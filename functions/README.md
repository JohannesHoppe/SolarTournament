# functions

Server code: Cloudflare Pages Functions of the same Pages project as the site (never a separate Worker). There are three:

- `turn.ts` (`GET /turn`): hands out short-lived credentials for Cloudflare's TURN relay, for players whose networks block direct connections. The TURN key stays here, read from the project's environment; the function keeps its own monthly budget of relay traffic and hands out nothing once it is spent or cannot be read. Its answers name only fixed reasons; what an upstream service answered goes to the function's log. `src/net/turn.test.ts` checks that.
- `push.ts` (`GET`/`POST /push`): the notification when a public tournament opens. It hands out the VAPID public key (none while it is not set up, and the game then offers no notifications), keeps and forgets subscriptions in the D1 database bound as `PUSH_DB`, hears the lead browsers of public tournaments say theirs is open (a room only as its hash) and, when a new one raises the number open, sends the notification to every subscriber whose number (from one to three open, the Host's choice) it reaches, at most one every 15 minutes (a new tournament heard within them announced once they are over), in the Host's language; it keeps to a daily budget of rows written, half of D1's free allowance. It answers only on the game's own domains (as `turn.ts`) and takes a subscription only with an endpoint on the browsers' push services (Google's, Mozilla's, Apple's, Microsoft's), so it never posts to an address someone else names. The pushes are encrypted and signed by `src/net/webpush.ts`; `src/net/push.test.ts` checks its rules.
- `admin.ts` (`GET /admin`): Johannes' page of the game's figures (push subscribers and sends, open public tournaments, the day's writes against the database's budget, the month's TURN traffic against its budget). It answers only a request with a valid Cloudflare Access token of its application, checked against the team's keys (`ACCESS_TEAM`, `ACCESS_AUD`, plain variables in `wrangler.toml`); without them it answers 404. `src/net/admin.test.ts` checks the token and the page.

Its variables are set in the Cloudflare dashboard (secrets) and in `wrangler.toml` (plain values); the repository's CLAUDE.md names them. Cloudflare builds and deploys it with every push.
