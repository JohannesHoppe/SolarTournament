# public/assets/planets

The maps of the planets drawn from real images (see `src/world/landmarks.ts` and `src/world/junkyard.ts`, loaded by `src/assets.ts`). Each map is cylindrical: longitude across, latitude from the north pole at the top to the south pole at the bottom; Earth's covers only the region beneath its arena. The page loads the `-1k` maps; the `-2k` ones only once the picture's quality asks for them (see `Landmarks.setDetail`).
