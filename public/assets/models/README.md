# public/assets/models

The two interceptor models, Johannes' own (not licensed). The game builds the hulls it shows in code (`src/ship/models.ts`) and takes from these files only the collider box, so both ships share one hit radius, and the drive flame's and glows' places.

- `human-interceptor.glb`, `alien-interceptor.glb`: the models.
- `extraction-summary.json`: their measured sizes (units).
