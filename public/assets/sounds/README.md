# public/assets/sounds

The one recording the game plays; every other sound is synthesized in code.

- `crowd-roar.mp3`: the crowd of the stadiums on Earth, heard through the broadcast (`src/music/crowd.ts`): ["RoaringCrowd.wav"](https://freesound.org/people/benfree/sounds/130568/) by benfree on Freesound, CC0 1.0 (public domain), made into a seamless mono loop of 17 s (22 kHz, 64 kbps; its last two seconds blended into its first). The game sends it through a stadium's overdriven loudspeakers itself.
