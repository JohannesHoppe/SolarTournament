# SolarTournament

A browser space shooter in an asteroid field, built with [three.js](https://threejs.org/). No shields, no sound in space, no drag: ships obey Newton, lasers punch straight through hulls, and a careless burn ends in a rock.

What flies, collides, burns and breaks behaves the way it would out there, as long as it stays fun.

## Run

```
npm install
npm run dev        # http://127.0.0.1:5173/
npm test           # unit tests (Vitest)
npm run e2e        # browser tests (Playwright; first once: npm run e2e:install)
npm run build      # static site in dist/ (runs the unit tests first)
```

## Deploy

The game is a static site on [Cloudflare Pages](https://pages.cloudflare.com/), project `solartournament` (`wrangler.toml`). Two stages, one branch each:

| Branch | Stage | Address |
|---|---|---|
| `stage_prod` | production | https://solartournament.games |
| `main` | test | https://test.solartournament.games |

Cloudflare builds every push to one of the two branches itself (Git integration: build command `npm run build`, output directory `dist`, Node from `.node-version`); no Cloudflare token lives in GitHub. Development happens on `main`; a release merges `main` into `stage_prod`. `test.solartournament.games` points to the branch alias `main.solartournament.pages.dev`; `www.solartournament.games` and `solar-tournament.games` (with `www.`) redirect permanently to `solartournament.games`, path and query included.

The project is a classic Pages project, not a Worker: the game is a static site, and its only server code is a Pages Function of the same project, `functions/turn.ts` (`GET /turn`), which hands out short-lived TURN credentials (see below), never to a request the browser marks as coming from another site (`Sec-Fetch-Site` other than `same-origin`; older browsers that send no such mark are answered, and a zone rate limit keeps scripts from collecting credentials in bulk).

Every page goes out with a Content Security Policy (`dist/_headers`, written by the build from `vite.config.ts`): scripts and styles of the site itself only (its one inline script, the redirect from the Pages addresses, by its hash; `blob:` for the audio worklets of the radio), connections to the site and to the Nostr relays (`wss:`), no frames around the game, no plugins; together with `X-Content-Type-Options: nosniff` and `Referrer-Policy: no-referrer`.

## Languages

The game speaks English, German, Spanish and French. It starts in the language the Host chose in the menu (the buttons at its foot, each language named in itself; the page starts anew in it), else in the first of the browser's languages it speaks, else in English. Every text on screen is translated, and so are the flight computer and the announcer, whose voices are rendered in each language: Nicole speaks the other languages in the sounds espeak-ng spells them in, with her accent. The regime's voice on Radio 2584 keeps its own English and German, and the titles of its tracks are their seeds, the same for every Host. The legal pages are German. English is the source: every text is written in English where it is used and translated through catalogs (`src/i18n/de.ts`, `es.ts`, `fr.ts`, keyed by the English text); `npm run i18n -- de` lists what a catalog still lacks, and the unit tests fail while one lacks anything.

**The essentials** are W, A, S, D, Shift, Space, X and the arrow keys or the mouse; both work at the same time, so keyboard pilots and mouse pilots share one layout. The up and down thrusters and the camera are extras. The pilot does not roll: the flight computer keeps the ship upright (see Flight).

**Mouse flight.** The pointer stays visible and nothing captures the mouse. Its offset from the screen center is the stick: at 25 % of the shorter screen side it turns at full rate, within 8 % of that around the center the ship flies straight, and a pointer that leaves the window lets go of the stick.

Gamepads with the standard layout (Xbox, PlayStation, most others in current browsers) work without setup. A pad whose layout the browser does not know is left alone: its axes may rest anywhere (a trigger or a throttle at full) and would fly the ship by themselves.

On phones and tablets touch controls appear: the fixed stick on the left turns the ship (drag up = nose up), a second stick appears under the right thumb and fires the maneuvering thrusters. Hold **Drive** for the main drive and **Fire** for the laser; **Brake** brakes to a stop, **Flip** (hold) turns the ship against the flight, **Hook** (hold) fires the hook and reels in. Pressing a key on a hardware keyboard hides the touch controls (the phone's volume keys and a headset's media keys do not), touching the screen brings them back; a hold button stays held while any finger is on it. On a phone (a touch screen less than 500 px high or 600 px wide) the HUD shrinks to the edges so the middle of the picture stays free: smaller buttons, the gauges as a slim row of labels over bars, the round's panel narrow beside the radar, messages and transmissions smaller and out of the middle, and the radio only its switch and the title in the top right corner (the phone's own keys set its volume). No piece of the HUD covers another: the round's panel, the alarms with the message below the crosshair, the transmissions, the radar, the gauges, the radio, the kill feed and the touch buttons each keep their own place, on a big screen and a small one, with keyboard or touch; on a low screen with a keyboard the transmissions run on the left beside the alarms' column, the radar shrinks and the gauges close up. A round is flown with the phone held sideways: held upright, a plate over the round asks to turn it ("Turn your phone sideways to fly."), with a phone turning on it; a solo round stands still meanwhile and goes on as soon as the phone turns, an online tournament does not wait. The menu works either way.

**Fullscreen.** On phones and tablets a round goes fullscreen by itself and, where the browser allows it, holds landscape; the menu and the pause menu have a Fullscreen button for every device. Browsers that do not let a page go fullscreen (the iPhone's) get it by adding the game to the home screen: the web app manifest (`public/manifest.webmanifest`, icons rendered from the seal) starts it without the browser's bars.

## Online tournament

**Online tournament** in the menu opens the list of tournaments. On top, the public tournaments running right now, each with its name, how many Hosts fly, whether bots fill it and the time left in the round, and a button to join (or to watch, when it is full). Below, a form starts one:

- **A name** of the Host's choice ("Kessler's Revenge"), up to 32 characters.
- **Public or private.** A public tournament is announced in the lobby for everyone; a private one is only found through its link.
- **With or without bots.** With bots, the lead browser fills all eight places and every Host who joins takes a bot's place; without, only Hosts fly.
- **Race, deathmatch, Last Clone Standing, Capture the Flag, the President's Fleet, or all in turn** (see Modes).

The room's code, name and rules live in the fragment of its link (`#t=kessler-s-revenge-k7m2pq&n=Kessler%27s+Revenge&pub=1`, `&bots=0` without bots, `&m=race` or `&m=mixed` for the mode), so they never reach the web server. The code is the name plus a random part: 6 characters for a public tournament, so two of the same name never meet, 20 for a private one (about 99 bits), far beyond guessing from the public relays. Starting a tournament invites friends at once: on a phone the share sheet opens, elsewhere the link is copied; the pause menu's **Invite friends** does the same any time. Whoever follows the link joins; when nobody is in the room any more, the first to come starts it again with the link's rules, so a tournament can be played forever. There is no game server: the browsers find each other through public Nostr relays ([Trystero](https://github.com/dmotz/trystero)) and then talk directly over WebRTC. Leaving the tournament and the list closes the connections to the relays.

- **The lobby** is one shared room on the same relays. The lead browser of a public tournament announces it every five seconds, and at once to everyone who opens the list; a tournament not heard of for 16 seconds leaves the list. Announcements are checked like every message from another browser. A tournament's listing only follows the browser that announced it, until that one has been quiet for 10 seconds (as when the lead moves on); a browser leads one tournament at a time, so its newest announcement replaces its earlier ones. The list keeps at most 50 tournaments and lets the one heard of longest ago go first. Until the lobby has listened for six seconds, the list says it is still looking.
- **Eight places per tournament.** A ninth Host does not fly but watches the broadcast, and the own clone is printed as soon as a place comes free; the HUD shows the watched pilot's gauges. A director cuts the broadcast: it follows the pilot in the thick of it (another ship close, a nose on an enemy, an enemy on its tail, a battered hull, in a race the leaders), holds a pilot at least 6 seconds and cuts only to one clearly more in the thick of it, at once when the followed one dies; every other cut is a wide shot from the side instead of the chase camera. Tab picks the next pilot by hand; 10 seconds after the last Tab the director takes over again. Hosts who were in the room first keep their places. In its first six seconds a newcomer cannot know yet who came first and counts every browser it is connected to: with eight or more, it watches.
- **Every Host has their own pilot.** Each browser simulates its own ship and sends its state 15 times per second; the other browsers predict the motion in between (a ship without thrust flies straight on) and blend corrections in smoothly: the shown ship moves on as predicted and the blend only takes out the correction, so it is drawn where the prediction says. The ships of a browser that has sent nothing for 2.5 seconds (a hidden tab) leave every screen until it sends again, and its Host does not count as flying.
- **The shooter decides about hits.** A beam that goes through a ship on the shooter's screen is reported to the browser flying that ship, which applies the damage and announces a destruction. Asteroid hits go to everyone, with the field time and the round of the hit (a hit for a round a browser has not started yet waits for it); the fragments are deterministic, so all players see the same ones, and a destroyed ship's wreckage is seeded with its death count, so it breaks into the same pieces everywhere, flying from where the ship's own browser saw it break up. A piece of wreckage shot or rammed bursts on every screen, and a Host who joins gets the pieces in flight together with the field. When two Hosts break the same rock at the same moment, the hit with the earlier field time gets the points; the other browser takes its own points back when it learns it was later. When two hits from different browsers use up a rock's last hit points, the later hit by field time broke it: its browser credits its ship, though it learns of the other hit only afterwards.
- **One field for everyone.** Where a rock stands and how it is turned follows from the seed and the field time. The lead browser shares its field time with the round clock 15 times per second; the others glide towards it and jump when they are more than half a second off. A newcomer gets the field time, every rock's remaining hits and when each rock broke, the motion of every hull piece a comet shoved (see Comets), the wreckage, the probes in flight and the ones taken, and learns from the first round clock which round runs; its clone is then printed again in the round's arena (on the grid in a race), since it was printed before the arena was known; a browser that starts over (see below) gets the same and rebuilds its field from it. The snapshot names its arena, so a newcomer builds the field in the right one. Every new round brings a fresh field in the next arena (see Arenas); rocks circling the center follow from the field time as well.
- **The lead browser** is the one that has been in the room longest and is still sending. It runs the bots and the round clock (in Capture the Flag with the sides and the cores, in the President's Fleet with his battleship) and brings newcomers' asteroid fields up to date. Any browser can take over this job at any moment: when the lead leaves, or falls silent for 2.5 seconds (a hidden tab runs no frames, a link drops), the next one takes over and adopts its bots with everything they had: name, ship, score, kills, deaths, hull, drive, thrusters, position, motion and whether their clone lives (a dead one boots its next clone 3 seconds later). Every browser works out the join times from the same reports, so all of them elect the same lead.
- **Who was gone starts over.** A browser that ran no frames for 2 seconds, or heard none of the others for 2 seconds and then hears one again, knows the others went on without it: it starts over as the newest in the room. It gives up the lead and its bots, joins the queue for the places behind everyone else, and takes round clock and field from the lead like a newcomer (its own score stays, unless the round changed meanwhile). It judges itself cut off half a second before the others judge it silent, so it is the one whose link failed that starts over. A browser that speaks again after 2.5 seconds of silence counts as sending only 2.5 seconds later, so it can report first that it started over. When two groups that lost each other meet again, the group whose lead is not the oldest takes the other group's world; with only two browsers, nobody can tell whose link it was, and the one that notices first starts over. Two browsers that lead at once (their join times too close to tell apart over the network) settle it: the one with the higher id starts over.
- **Nothing from other browsers is trusted.** Every message is checked before the game uses it (finite numbers in plausible ranges, callsigns up to 16 characters, at most eight ships per browser, messages up to 64 KB). A message about a ship only counts from the browser that runs it. A shooter cannot hit the same ship, or the battleship (a laser one part a shot, a torpedo's blast each part once), more often than its laser fires, and every kind of report has a limit per browser and second: 45 ship states (three times the rate they are sent at), 96 beams, 96 hits, 20 asteroid hits, 8 destructions (a nova can take every ship a browser runs at once), 20 pieces of wreckage, 12 torpedo launches, hits, detonations, probes taken and novas (one shared limit), 2 cheat reports. Counts (score, kills, deaths, gates, items) must be whole numbers. A ship dies once per clone: a destruction only counts for a living ship and a death count that goes up.
- **Plausibility: cheaters are named.** Every browser checks, roughly, whether what another browser reports about its own ships could have happened; the bounds lie so far beyond what a ship can do that lag, lost or bunched messages never make an honest browser look like a cheater. Their windows run on real time, not on the game's time, which runs slower on a device below 20 frames a second. A ship must not move farther between two states it is seen alive in than 750 m/s (three times the speed limit) plus 500 m allow, twice within 30 seconds; only what every browser sees makes a new clone that may be printed anywhere, with a fresh load of torpedoes: a death its browser told everyone of (the load is fresh with its first state 2 seconds or more after the death; one that comes earlier, bunched with the death by lag, still counts as the last clone's), a new round, a nova's reprint, a start over of its browser (all free for 10 seconds; a start over keeps the nova core a clone held, as its browser may keep the clone); a state that only says the ship died and lives again changes nothing. A laser hit on an own ship counts only from a beam that starts near its shooter (within 1 km plus half a second at that speed) and passes within 1 km of the ship; a rock between the muzzle and the ship, as this browser sees them, takes the beam (lag may let one slip in, so that is no cheat). A torpedo hit only names a torpedo that flew here too and went off within 1 km of the ship; a torpedo another browser says went off more than 1.5 km from where it flies here flies on. Every browser is told of every beam, and that is the evidence for what a ship did elsewhere: a rock it broke, a torpedo it shot down (any browser but the one that launched it) and a part of the battleship it hit count only with a beam of that ship that ended within 1 km of them in the last 5 seconds (a torpedo's hits on the battleship with that ship's torpedo going off there), and a kill counts for the killer only when a beam of its passed within 1 km of where the victim broke up, a torpedo of its may still fly, its nova core went off, or it was within 1.5 km (its drive plume burns, its nova reaches 800 m); otherwise the death counts without a killer. A browser that has only just come takes rocks and the battleship's hits on trust, the beams before it came being unknown to it. An asteroid hit counts only within 5 seconds of the own field clock, and a browser's hits in a round come in the order of its field time, give or take a second for a field clock that follows the lead's and may jump back (an earlier time would take the points of whoever broke the rock). A probe taken elsewhere must be one that could exist (shown this round, or dropped by a known ship's dead clone), and a probe this browser has is only taken by a ship within its reach plus 500 m and half a second of the ship's flight; one refused for that still counts, for the nova core that ship may set off, as a probe of unknown contents (lag may put an honest taker too far). A ship hooks a ship this browser runs only within the hook's reach plus 500 m, and the cable is at least as long as the way between them. A peer first heard after this browser has settled cannot claim to have been in the room longer than the lead: it lines up 2 seconds behind it, so it can never make the lead step back; only a lead whose join time lies within a second of another's known as such steps back for it. A newcomer believes the join times it hears while it settles; from then on every browser checks once a second whom the others follow (their states say, a peer's vote for itself not counting): when most of the live peers that name one follow another peer than the one it would elect, that peer's own join time is believed and the one it would have elected lines up behind it, and a browser that led alone (it reached the others only after settling) starts over behind them and takes their world. Browsers that each lead alone (two that reached each other only after settling) have nobody to vote between them and cannot tell an honest older peer from a liar: they settle it as two that joined at once, the one with the higher id steps back and takes the other's world, so they never play on in two worlds. A liar can take the lead of such a room of two this way, never of one where others vote. A browser that starts over gets the field again every time (at most once in 2 seconds); what the checks know of its clone is cleared at most once in 10 seconds. A new round number is taken only once the running round is (nearly) over, and a round clock no lower than −60 s; the lead's round clock names the room's modes, and every browser plays those, whatever the link or the lobby said. A nova only goes off from a living ship that took a nova core (its probe; or its state says it holds one when this browser first sees it, or within 5 seconds of taking a probe this browser did not have), within that reach of where the ship was; anything else never goes off. A clone launches no more torpedoes than it carried (with its tubes up to the online cap) and took from probes, plus 2; more are not launched. A ship's kills grow no faster than the deaths everyone saw it cause (two for a nova, minus one for a nova's victim), plus 2. A browser that catches a ship this way rejects what it can, tells everyone once a round (`ch`), and as soon as a majority of the Hosts with a vote besides the accused, at least two and the own one included, say a peer cheats, everyone sees CHEATER with its Host's callsign (two of three, three of five, four of eight). What was said in a round goes with it, so single false reports never add up over rounds. A vote is a place: only the eight browsers that came first by their join times (those whose clones fly) vote, and only they are counted, as long as they send; a browser's word that it flies buys none, so a cheater who comes in to watch, with as many tabs as it likes, cannot take the majority. A cheater with tabs among the first eight of a room does vote with each of them: a room's places are first come, first served. A peer's own word never counts against it, so a single liar cannot frame anyone, and two tabs of one Host cannot vote an honest one out of a fuller round; with only two browsers in a tournament, nobody is named. A peer named a cheater is cast out: every honest browser comes to the same vote, sends it nothing more and takes nothing from it, and its ships leave the tournament as if it had gone (its bots are adopted, the lead is elected anew); the browser cast out is told so ("The other Hosts named you a cheater …") and goes back to the menu. Only a newcomer takes an asteroid field, once, from a browser that was there first. Callsigns lose control and invisible format characters on every screen alike (the own menu included), so none is left empty.
- **Rounds** last five minutes for everyone; the scoreboard shows over the running game, and the next round starts after 12 seconds. Meanwhile nothing scores and no mode's rule moves on: no kill, gate, core or part of the battleship counts, so the scoreboard stays what was paid out. A round is not decided in its first 3 seconds, while the other browsers' ships may still carry the last round's deaths and finishes. The pause menu does not stop the tournament.
- **A relay for strict networks.** Some networks (e.g. strict company firewalls or carrier-grade NAT) block direct connections between browsers. For them the game uses Cloudflare's TURN relay: when joining, the browser asks the game's own site (`/turn`, a Cloudflare Pages Function in `functions/turn.ts`) for credentials that hold one hour, and fetches fresh ones every 50 minutes for the connections it has and the ones to come; the TURN key itself stays on the server. Only the game's own domains answer (the raw Pages addresses and pages of other sites get nothing), and a rate-limiting rule of the Cloudflare zone (5 requests per 10 seconds and IP) keeps scripts from collecting credentials in bulk. The data stays end-to-end encrypted (WebRTC); the relay only passes it on. Cloudflare's first 1,000 GB a month are free, and Cloudflare sets no spending cap on TURN, so the function sets its own: it reads the relay's outbound traffic of the month from Cloudflare's analytics and hands out no credentials beyond 500 GB, or when that number cannot be read. Without a relay the HUD says why next to the tournament's name ("Relay off: monthly budget spent", "no answer", …), so a Host who cannot connect knows where it fails. Without an answer within three seconds (the dev server, a project without a TURN key) the game connects with STUN alone.

For development, `?local=1#t=code` connects tabs of the same browser without the internet.

## Flight school

The flight school has five courses, each played on its own from the school's plate: **Basic training** (flying), **Racer** (the race), **Gladiator** (the fight), **Arsenal** (torpedoes, overdrive, probes, the hook on a ship, the nova core) and **Tactician** (how to win a dogfight). The menu leads with the flight school until a Host has completed the basic training; after that the solo round is the main action (Enter opens its choices, Enter again launches it). On the school's plate Enter starts the first course not completed yet. Each course remembers the drill a Host has reached, by the drill's name, so drills added to a course later do not move it: after a reload it continues there ("Continue at drill n of m"), with the autopilot as the drills before left it, and "Start … over" below the course begins it again. A completed course says so for good ("✓ Completed."), also when the Host trains again, and the menu's button counts the completed courses; after a course the school's plate comes up again, with the next course a key away. Each course trains one maneuver per drill, in the order a Host needs them. Each drill comes with a short spoken line, the keys as big keycaps (the spoken words name no keys; the keycaps show those of the Host's keyboard, gamepad or touch screen), and markers in space (orange diamonds, a course of rings built as a race's coils and bracketed like its gates, red debris). A drill waits until the pilot has really done it, some are repeated two or three times, and a failed attempt or a dead clone starts the attempt over; a drill done counts only once the clone has lived through it 1.5 seconds more, so one flung into a rock right after (off the hook, say) does the drill again. Training clones are free: no sponsor break. After every drill the flight computer praises the pilot and explains the physics behind the maneuver. Every attempt runs in clear phases, one after the other: what is left to say of the last one (the praise, or why it failed) to its end, then the instruction to its end, and only then the drill's markers, drones or bots show up and the drill counts. Her lessons are never cut off: a new one waits until she has finished the last, and her other lines (hits, asteroids, warnings) stay silent while she teaches; the HUD shows them anyway.

**Basic training** (10 drills, the autopilot on throughout):

1. Briefing: Nicole introduces herself ("Hi, I am Nicole. Your personal flight computer."), then the world of the games in four sentences.
2. Turning: three markers into the crosshair (arrows or mouse), at rest, where the stick turns the nose.
3. Fine aim: Shift turns slowly; center a far marker exactly.
4. Cockpit view: C switches into the cockpit and back (not given on touch screens, which have no camera switch: Nicole goes straight on to the next drill).
5. Main drive: W up to 50 m/s.
6. Brake: hold S, the flight computer flips and burns until the ship is at rest.
7. The curve, with path steering (see Autopilot): the ship drifts at 100 m/s at four markers, each in a blue sphere 100 m in radius: 400 m ahead, then a quarter turn to the right on an arc of 800 m radius, and 600 m straight on after it. The stick bends the path through the spheres, the racing line runs through them, and letting go of the stick flies straight on to the last. A pilot more than 2.5 km from the next marker starts the attempt over.
8. Stopping at a marker, near and far: burn, flip, burn. It counts once the ship rests (below 10 m/s) inside the blue sphere around the marker, 200 m in radius.
9. The impact warning: drifting at a rock with 100 m/s, braking or steering around it.
10. Basic training complete: racer or gladiator next.

**Racer** (8 drills):

1. What the racer learns: rings, coils, the racing line and a clean start.
2. The X: a course of four rings (each counts from either side), as wide as a race's gates and laid out like one: a gentle slalom, the rings about 830 m apart, with the racing line through them and the X where the flight crosses the next ring's plane, as in a race; steered into the ring, it glows azure. A ring missed (its plane crossed beside it) starts the attempt over ("Missed").
3. The coils: three rings in a long line 1.1 km apart, each through its inner third (as a race's gates, see Modes), so each throws the ship on by 40 m/s; a ring passed off-center or missed starts the attempt over ("Off center").
4. Brake zones: the ship drifts at the speed limit (250 m/s) at three rings, the first 1.5 km ahead, the second 630 m to its right, so the racing line bends with about 220 m radius between them, tighter than path steering turns at that speed (415 m), and glows orange before the bend. Braking before the orange makes the ring; a ring missed starts the attempt over ("Too fast for that bend").
5. The line at full speed: five rings weaving over 2.7 km, the line bending no tighter than about 800 m (never orange, even at a coil's 290 m/s), each ring a coil. The course has to be flown at 200 m/s on average along its racing line, plus 4 seconds for the burn up to speed (the pilot starts at rest, turned to the first ring; the marker counts the seconds left): only a drive held all the way gets there ("Too slow"), path steering bending the flight through the turns. A ring missed starts the attempt over.
6. The start: 3, 2, 1, BURN! in big neon while the clamps hold the ship; the drive has to light within 0.3 s before BURN! or 0.2 s after it, as in a race. Lit earlier, the drive stalls ("Too early"); not lit in time, the attempt starts over ("Too late").
7. The hook: 500 m off a rock, facing it and drifting past it at 50 m/s; hook it, reel in, swing around it and let go faster than 65 m/s (a few seconds of reeling). Letting go slower starts the attempt over.
8. A racer now.

The ring courses and the curve lie ahead of the pilot, or, where they would reach out beyond 85 % of the arena's edge, run towards the arena's center instead (the pilot turns to the first ring; the curve, the brake and the full-speed drills turn it there). A pilot more than 2.5 km from the next ring has lost the course and starts the attempt over. Every other drill with a marker more than 100 m off shows the racing line to it too: from where the pilot was when the marker came up (or last moved 10 m, so it keeps pointing at a sparring partner, drone or torpedo on the move) to the marker, ending there, bowing around rock like a race's. The flight school loses no pilot to deep space: beyond the arena's edge the HUD says "Return to the field" without a count; only the belt beyond takes a ship.

**Gladiator** (16 drills):

1. What the gladiator learns: the laser, the heat, and the dogfight.
2. Shooting a resting drone: armor shrugs the laser off, five hits into the drive blow it up. A target drone keeps its drive turned to the pilot, wherever the pilot flies.
3. Shooting a drifting drone, again into the drive (the laser hits instantly, no lead needed).
4. Firing until the laser overheats.
5. Cooling down in the shadow of an asteroid.
6. Free drift: T switches the autopilot off; the drift lessons that follow need it.
7. Drifting: let go, nothing slows the ship down.
8. Looking back while drifting: in free drift the stick only turns the nose and the ship slides on, the course stays (the prograde marker shows the course); the praise sets it against the autopilot, where the stick bends the path.
9. Flip and burn by hand, twice: hold X and W together; the drive fires once the nose points back; the S brake does not count here. The drill counts once the drift along the course is gone; a little sideways drift may remain.
10. Jinking: a gunner on the tail fires red shots at where the ship was a moment ago; pushing left and right with the thrusters (A/D) makes them go past. It counts after four changes of side; turning and drift do not matter, a hit only sparks.
11. Dodging debris that drifts straight at the ship, twice, without turning (more than 45°).
12. Autopilot back on (T).
13. Chasing a bot that flies but does not shoot: it runs, staying on its tail opens its drive.
14. Fighting a weak bot that shoots back: keep the armored nose on it, slide, and work onto its tail.
15. Final exam: a real bot that knows the trick too. Win the dogfight.
16. Cleared for the tournament.

**Arsenal** (8 drills):

1. What the arsenal holds: torpedoes, the overdrive, the probes and the nova core.
2. Torpedo: two in the tubes, a target drone 1.2 km ahead; keep it near the crosshair until the lock holds, launch, and hit it with a torpedo (the laser's hits do not count). Both launched without a hit starts the attempt over.
3. Shooting one down: the drone, 1.5 km off, launches a torpedo at the pilot; the HUD marks it ("Torpedo"); the laser has to hit it before it arrives. Hit by it ("It got you"), or it gone past, starts the attempt over.
4. The overdrive: from rest, one press and the ship is past 140 m/s.
5. A probe 400 m ahead carries two torpedoes and waits there: fly through it.
6. The hook on a ship: an unarmed bot 600 m ahead runs; hook it and reel it in within 300 m.
7. The nova core: the clone holds one, a drone 500 m ahead; fire, and both go up (the next clone is on the sponsors).
8. The arsenal is ready.

**Tactician** (11 drills; every sparring bot of the flight school fights from a cool laser):

1. What the tactician learns: most clones die flying a straight line.
2. The dodge, twice: debris drifts straight at the ship at 150 m/s from 600 m, too fast to slide out of its way; a thruster tapped twice kicks the ship aside. It counts once the debris is past and a dodge was fired, without turning (more than 45°).
3. The shove ("dirty is the point"): the ship and a drone drift side by side at 20 m/s towards a rock 200 m ahead, the drone 45 m off the ship's left, its way passing 20 m off the stone. A dodge into the drone as the rock comes up throws it at the stone at about 26 m/s; the drone starts with 15 hull points, a wreck already, so the stone finishes it, a knockout. It counts once the shoved drone touches rock or goes down; the rock left behind starts the attempt over.
4. On the tail: an armed bot (skill 0.15) starts 300 m behind the ship, its nose on the drive; turn the armored nose to it and shoot it down.
5. Bursts: an armed bot (skill 0.25) 400 m ahead, shot down without the laser ever overheating ("Too hot" starts the attempt over).
6. Shooting in free drift: the ship drifts at 100 m/s, the autopilot on, past an armed bot (skill 0.15) that starts 250 m to its right and 600 m ahead. Switch to free drift (T), turn the nose onto the bot while the ship slides on, and hit it three times with the nose more than 60° off the flight; then the autopilot back on. A bot shot down with fewer such hits starts the attempt over ("Sideways"). The same tip comes in a deathmatch (see Nicole coaches).
7. Cover from a hunter: the ship 150 m off a rock, facing it, an armed bot (skill 0.5) 1.2 km off to its right; three seconds in a row with the rock between them (the HUD marks the spot in the rock's lee, ahead and to the left).
8. Cover from a torpedo: the same, with a drone that launches a torpedo at the pilot (it arrives in about 7 s, the dash into the lee takes about 3); the rock has to break its lock. Hit by it, or shooting it down instead, starts the attempt over.
9. A comet (see Comets): the ship 150 m off a rock, facing it, a comet coming from its right, its route 150 m above the ship, its head 2.25 km off; the head passes over, the shower engulfs the ship. Get into the rock's lee (the HUD marks it) or turn the armored nose into the shower; two pieces into the drive start the attempt over ("Your drive took the shower"). It counts once the shower has gone by.
10. Final exam: a bot as good as the field's middling one (skill 0.5). Win the dogfight.
11. A tactician now.

## Radio 2584

The tournament broadcaster pumps hard techno into every cockpit, composed live by the game with [Tone.js](https://tonejs.github.io/). There are no fixed tracks: every round grows its own track from one of 1,168 titles, and a title comes again only by chance (within 20 rounds about once in seven times), unless someone remembers it. **The title is the seed**: "Orbit Terror" always grows the same track, note for note.

**Musical direction.** The maintainer is a big fan of Kraftwerk and Daft Punk, and of everything early techno had to offer: hard beats and that certain underground feeling. It was a great time that he was maybe a little too young for, so we live it out here. Radio 2584 therefore sounds like the underground: driving, raw and distorted, with machine-like sequences, and now and then the German *Autobahn* feeling of Kraftwerk, robot voices with a rolling R included. Tracks must never become predictable: every round takes its own path.

Decisions so far:

- Hard and fast beats beat polite ones; chiptune and lounge music do not fit.
- Schranz and generic rave are not the maintainer's taste and only play rarely.
- German words in the robot voice, but only now and then.
- Daft Punk styles and elements are always welcome: loops that a filter opens and closes, phaser, pumping compression, vocoder robot voices, phrases chopped into the beat word by word, and the raw, distorted early sound.

- **Hard, but not exhausting.** Mostly 126 to 148 BPM, the fastest at 152: a round lasts five minutes, but people play many rounds, and peak-time speed and full distortion wear the ears out over an evening.
- **Flavors** (how often they come up):
  - *Hard* (4 in 24): an offbeat bass (rolling in one track in three) under a heavy rumble, 140–148 BPM.
  - *Industrial* (4): bit-crushed hats, cowbells and claves in Euclidean patterns, a little swing, 134–141.
  - *Acid* (4): a squelching 303 line carries the track, 138–144.
  - *EBM* (5): electronic body music, a sequenced 16th bass (root, root, octave, root, accents before the beat) or an octave bass whose 16th echo turns it into a pulse (Giorgio Moroder), arpeggios in one track in three, 132–140.
  - *French* (5): a chord loop that a filter opens over four bars and closes over the next four, phaser, pumping, 126–132.
  - *Schranz* and *Rave* (1 each): the fastest (148–152) and tom-heavy, or stabs or a hoover (142–148).
  - *Motorik*, one track in thirteen: Kraftwerk's machine pop. An electro beat, octave bass, square-wave plings, a pad, 126–134 BPM, a German title and a German robot voice.
- **Strategies.** The title also picks how the track develops, so no two rounds follow the same recipe:
  - *Classic*: grooves and peaks, kick-less breakdowns, re-entries.
  - *Relentless* (after Jeff Mills): no breakdown at all. Layers drop out for two bars at irregular moments, every 16 bars the tops take a bar off, and twice the track strips down to the kick and few of its lines for four bars.
  - *Hypnotic*: one long accumulation over two thirds of the round, layers entering as the energy climbs, one filter dip before the finale.
  - *Movements*: the first half belongs to the lead, then four bars of kick and bass, and the second half to a sequenced bass; the lead never returns (it only enters once the energy reaches it, so the gentler leads of acid, French and schranz tracks are not heard in this form at all).
  - *Switcher*: the felt tempo changes; a half-time section (kick on one, clap on three) and a broken-kick section (kicks on one and the "and" of three) between the straight ones.
  - *Fake drop*: after a breakdown, four bars that sound like the drop but hold back the low end, two bars of gap, then the real drop.
  - *Polymeter*: percussion loops of 5, 7 or 9 steps and a 7-step acid line drift against the bar and fall back to the track's regular loops in the finale (12 or 16 steps for the acid).
- **Surprises.** Every round gets three to five of these, each kind at most once, 12 bars apart (8 where a track has no room for more), after stable stretches (a big surprise works best when the listener is sure what comes next): a filter dip of four bars, a delay throw that swells into feedback, an air-raid siren, a bit-depth drop on the hats (in industrial and EBM tracks and half of the others), a key lift of 2, 3 or 5 semitones for the rest of the track (only in the last stretch before the finale). Half of the breakdowns open with a bomb into the reverb. Breakdowns end in a rotating way: a beat of silence, a kick roll (quarters, eighths, sixteenths), a stutter, or a rug pull (a whole bar of silence). A section before a breakdown (a peak or a groove) may die in a tape stop: bass, acid, hoover, bell and arpeggio slide two octaves down, the level falls away.
- **The kick** is a sine whose pitch drops in two stages, saturated hard, with a noise click on top, and every track has its own:
  - the pitch starts at 10 to 26 times the fundamental, falls to 4 to 9 times it within 8 to 25 ms, then to the fundamental within another 60 to 180 ms;
  - the body rings for 40 to 80 % of a beat;
  - the distortion is gabber (tanh, then atan), hard clipping, a warm tanh or a metallic wave fold, depending on flavor and seed;
  - the click, the brightness (lowpass at 2.5 to 9.5 kHz), the rumble's upper limit (110 to 230 Hz), its level and how fast it swells back all come from the title.
  
  The fundamental lies between 41 and 62 Hz and sets the key of the track.
- **The rumble.** A copy of the kick runs through a long reverb, distortion and a band from 30 Hz up to 110 to 230 Hz (set per track), in mono. Every kick ducks it, and it swells back before the next one: the low end breathes on the offbeat. Bass, acid and stabs pump with the kick as well. The bass leaves the sub to the rumble and mostly stays off the kick; only the EBM and Moroder bass lines run straight through it.
- **Patterns.** Every step of a bar has a weight for every instrument; a step plays when its weight beats the instrument's density, and density follows the energy of the track. More energy adds notes in a fixed order instead of reshuffling them, so build-ups sound intended, but the density ranges are narrow: energy brings in the strong steps and a few weak ones and never fills every gap, so even the finale keeps its groove (about 40 to 55 hits a bar across all parts). More energy comes from layers, filter and drive, not from more notes. Hats run in eighths with a sixteenth here and there, open hats on the offbeat, claps on two and four (ghost claps only in fills), percussion in Euclidean rhythms of at most two hits in five steps on a loop of 5 to 16 steps that drifts against the bar; arpeggios play eighths. Every 16 bars each part may mutate a little; the kick never does.
- **One key, room to breathe.** Every note of every part, whatever the chord shape, the motif or the acid line asks for, lands on the track's natural minor scale (a note outside it moves down a semitone), so the parts never rub against each other, and a key lift moves them all together. Of the melodic parts (acid, lead, chords) and of the extra percussion (ride, toms, cowbell and claves) at most two play at once; which one rests changes every eight bars.
- **The acid line** loops over 12 or 16 steps, its note sets and step weights after Vitling's [Endless Acid Banger](https://github.com/vitling/acid-banger) (CC BY 4.0). Accents throw the resonant filter wide open, slides glide into the next note, often an octave up.
- **Arrangement.** A round runs intro, grooves, peaks and breakdowns on an 8-bar grid, with short strips of 2, 4 or (in polymeter tracks) 8 bars between some sections; energy moves through breakdowns and re-entries. In a breakdown the kick drops out while hats and a thin bass without its low end keep the rhythm going, the filter opens, a noise riser climbs over the last four bars and the breakdown ends in one of its endings (see below); the next section crashes in. At the end of a section a fill marks the phrase, and now and then within one (two in five 16-bar phrases, one in five 8-bar phrases): kicks added or removed, a hat roll, a clap burst, a tom run. The last minute of the round is the finale with every layer and the most distortion (85 % drive: some headroom stays); after the round an outro takes the track down.
- **Loud, not harsh.** The mix ends in a glue compressor and a soft clipper instead of a hard limiter. The shared dotted-eighth echo (set to each track's tempo, like the bass's sixteenth echo) and the reverb sit well behind the dry parts (echo send 0.3 with 25 % feedback and no lows, reverb send 0.5), so no note is smeared across the beat.
- **More instruments.** Besides kick, rumble, hats, ride, clap and bass: Euclidean toms, an 808-style cowbell (two square tones at 587 and 845 Hz through a band at 2.64 kHz), claves, an FM bell, a hoover, a square-wave arpeggio, distorted chord stabs, the french chord loop and the motorik pad.
- **The voice of the regime.** A robot voice announces the station and the track ("Radio twenty five eighty four. Now playing. Orbit Terror.") and drops the propaganda of the Orange President and his sponsors over the music, most often 5 to 8 times a round (2 to 11 in all): at section changes and now and then in between, in the finale more often. It speaks sentence after sentence, or chops a line onto the beat one word per eighth. Every word must stay understandable: the clear voice carries it, a touch of ring modulation, bit crushing and grit only colors it, a compressor makes it loud, the music steps back while it talks, and its last word is thrown into the echo. German now and then; in motorik tracks mostly German.
- **The announcer** cuts in over the radio after kills: static, a cynical line, static. "An excellent death for Juno." "The alien is dead. Now our nation can grow again." Human callsigns are spoken as "pilot" (the voice is rendered ahead of time) and shown by name. He comments on kills and on crashes into rocks (those of the ships this browser runs; another browser does not say how its ships crashed); a clone lost in deep space or to wreckage goes uncommented, and so does every death in the flight school, which is on no broadcast. At the start of a round the announcer opens the broadcast. He is driven hard into his own compressor and the music steps back to a fifth while he talks, so he stands clearly above the loud, compressed track. Two voices never talk at once: an announcement waits until the voice on air is through and no line of the track is due within five seconds, and is dropped after eight seconds without room.
- **Now playing.** The title of the running track, with flavor and tempo, is always in view in the top right corner. The note button next to it switches the radio off and on (also key M), the slider beside it sets the volume (remembered, and shared with the radio page). A click on the title opens the radio page.
- **The radio page** (`radio.html`): enter any title, or roll a random one, and the track it grows plays again in the browser: the shape of the track as a bar of sections, a playhead that can be dragged (or moved with the arrow keys) to jump anywhere in the track, a volume slider, the transmissions on screen. Since every note follows from the title and the position in the track, a jump plays exactly what the track holds there. "Download WAV" presses the whole track (5 minutes plus outro) offline into a 16-bit stereo WAV file of about 55 MB. Rendering time grows faster than the length of the music, so the track is pressed in 20-second chunks, each started 8 seconds early so reverbs, echoes and voice lines are already sounding at its seam, and the chunks are crossfaded; it takes one to two minutes.
- **The flight computer** has a voice of its own, independent of the radio: a natural, breathy, quick woman's voice that flirts with the pilot while preparing it for death. Whatever the screen tells the Host, it also says: damage reports, impacts, a cracked asteroid, leaving the field, the lost clone and the sponsor's pitch, the end of a round, and every step of the flight school. Its lines are rendered whole, not word by word, so they sound natural.
- **The crowd.** The Games are watched on Earth, in stadiums packed for the public viewing, and the broadcast carries their roar into the headset (vacuum carries none), so it follows the radio's volume and switch and fades with a lost clone's link. It is a recording of a roaring crowd, looped and sent through the stadium's overdriven loudspeakers (a soft clip and a broadcast's band); when it erupts, a second layer of it joins, off in time and a little higher. It rises with every number of a race's countdown and erupts at the start.
- **Nicole coaches in real rounds.** The first round a Host plays of each mode opens with her briefing right after she reports in (online once the round's mode is known, in every round of a mixed room): what the mode is about and how to win it (race, deathmatch, Last Clone Standing, Capture the Flag, the President's Fleet). In the fight she gives a tip the moment it matters: a ship ON YOUR TAIL (turn the nose to it), a laser overheated (short bursts, only when the crosshair glows), a torpedo inbound (shoot it down or put a rock between), and in a deathmatch with the autopilot on an enemy within 500 m, more than 60° off the nose and crossing faster than 60 m/s (free drift: slide on and turn the nose onto it). A tip comes at most once a round and three rounds long, a briefing once; then the Host is trusted with it. The browser keeps what it has heard. Not in the flight school, which teaches on its own.
- **Transmissions on screen.** Whatever the voice and the announcer say runs across the screen while it is spoken: the regime in orange neon, the announcer in blue.
- **The voice is pre-rendered.** `npm run voice` speaks every word and every sentence of `src/music/lines.ts` with [espeak-ng](https://github.com/espeak-ng/espeak-ng) (its robosoft variant for the regime, a livelier voice for the announcer) and the flight computer's lines with the neural voice Kokoro (in English; in German, Spanish and French Nicole speaks as her clone, made with Chatterbox, see `tools/voice/README.md`) into MP3 sprites at build time (`npm run build` renders it; it is not kept in the repository; the Kokoro model is pinned to one revision, and a build whose lines, tool and engine versions did not change copies the sprite from the build cache); the game plays whole sentences, so they keep their melody, places single words on the beat, and needs no speech engine. Browser speech synthesis cannot be used: its output can neither be routed through Web Audio nor timed to the beat, and it sounds different on every device.
- **Everyone hears the same beat.** In an online tournament the room code and the round number choose the title, and the music runs on the lead browser's round clock. Every note is an integer hash of seed, bar and step, so a browser can jump to any point of the track; it compares its music with the clock several times per second and jumps when they drift apart. All Hosts of a tournament hear the same note at the same moment (up to the network delay).
- **Hangar.** In the menu the arena's groove comes through the hangar wall: lower energy, filtered, never peaking. The flight school plays no music at all, so every word of Nicole is heard.
- The radio sits in the cockpit and plays straight into the headset, not through the hull. When the clone dies, its radio fades into the distance; the next clone hears it clearly again.

## The universe

SolarTournament has a universe of its own. It borrows two principles from science fiction series we love:

1. **Realistic physics**, as in *The Expanse*: Newtonian flight, no sound in vacuum, no shields, hulls that break.
2. **Consciousness transfer into clones**, as in *Altered Carbon*: death is not the end. But over a live link and with a memory that never breaks, as for the expendable of *Mickey 17*: every death is lived through.

Humanity has settled the solar system. Fast fusion drives make hard burns between the planets possible, and daredevil pilots whip their ships around gravity wells at extreme speed for the thrill of it. The SolarTournament grew out of that daring and became the greatest entertainment of its time: pilots, printed clones of their Hosts, fight each other to the death in ships among the asteroids, while audiences across the system watch from a safe distance. Gladiator games for the space age.

The clones die, and the Hosts come back. Their minds are linked to cloned human bodies; when a ship is destroyed, the Host wakes up in the next clone, in the next ship. That is why every round has respawns, and why the audience never runs out of champions. The clones come out of a 3D printer: disposable bodies, printed by the dozen, and everyone knows it.

The ships are not printed. Centuries of war left the system's depots full of old fighters, decommissioned, rusting in their rows, and the Games fly those: cheaper to burn them up in a show, clone and all, than to scrap them. Every interceptor that launches has been patched, repainted and sent out again more often than anyone counts, so none of them looks new. Only the President's own battleship comes fresh from the newest dock, and it shines.

**What the hulls look like.** The human interceptor wears olive paint over riveted panels, chipped down to bare metal at the edges, streaked with rust from every seam, grimy, stenciled over and over (a hull number, NO STEP, FUEL, the depot's mark); its stern, what a pilot sees most, is a drive block with steel ribs and vents, two nozzle bells blued by heat, and red tail lights on the fin tops and the stern. The alien interceptor is dark, in a fine pattern of scales, worn and scarred. The Sovereign is a gift of the regime and the least worn. Every fighter's paint lies under a thin clear lacquer, and its bodies are shaded round while boxes, caps and blade edges stay sharp: the sun, a drive's light or the hangar's lamps show on it as a small, crisp glint that slides across the hull as the ship turns, and a flat panel flashes for the moment it mirrors the sun. Out there no air dims the sun, so that flash blinds, with a wide halo, and the nearer the sun the harder: in the Corona twice as hard as in the belt. Where the paint rusted or chipped, the lacquer is gone, and scratches dull it. The President's battleship is polished gold under a clear lacquer whose thin film plays in all colors, its bridge in pearl, its flight deck deep red, with flakes of glitter in the lacquer that sparkle even in its shadow. The world ship of the Derelict carries the battle that broke it: meteorite craters with raised rims, burns tinted blue and violet by the heat around a black core, soot streaked along the hull, rust, and the last embers glowing in the deepest pits. The tournament's rings are grimy industrial plating with hazard stripes and stenciled coil numbers, each station module carrying a sponsor's sign. Sponsor probes are worn hulls with solar cells, torpedoes carry warhead bands, wreckage the torn paint of the fighter it was. All of it is drawn in code on small canvases (256 pixels) from fixed seeds, so every session shows the same wear, shared by everything that wears it; it is look only and changes no rule.

The one who receives all of it is the **Host**. Every player is a Host and is addressed as one: the person at the other end of the link, the host of everything the clones live through. The Host is bound to the clone by a live link. The clone flies and fights on its own, because only a mind inside the cockpit is fast enough: every radio link lags, and in a dogfight a fraction of a second is a lifetime. But the link carries so much that everything the clone lives through streams back into the Host's memory as it happens. When the clone dies, the Host holds all of it, every memory and every pain, the death included. A Host remembers every death, and the Host's brain has to cope with it. Dying hurts, and nothing about it is free. The clones die, but the soul rots a little more each time. (This is where SolarTournament leaves the Altered Carbon model behind, in which a stored memory is loaded into a new body and the death itself is lost; ours is closer to the reprinted expendable of Mickey 17.)

**Whose eyes we see through.** In the hangar, in the menu, we are the Host. When a round starts, the screen says "Establishing live link to your clone", the picture breaks up, and from then on we are the clone in the cockpit: the game plays from the pilot's perspective. When the clone dies, the link is lost and we are the Host again, sitting through the advertisement that pays for the next body; when the sponsor is happy, the link is established to the next clone and we are back in the cockpit. Everything the Host sees and hears arrives over that link. When a hit or an impact shakes the clone, the link stutters: the picture breaks up like a corrupted video stream, the radio drops out, static crackles in the headset. When the clone dies, the link breaks down until the next clone is printed: the stream loses its key frames, the clone's last picture stays and rots for 2.2 seconds, carried along by every turn of the camera and burnt by everything that moves, until fresh blocks bring the picture back (a datamosh; not with reduced motion). Even the idle link to the clone hangar flickers now and then.

The future is broken, and it glows. Neon signs flicker over everything, every surface is for sale, every picture comes over a link that can break. The tournament's own sign is sun orange; the sponsors advertise in its complement, a cold azure blue.

It is a society without morals. A new clone is not free: the Host pays with attention. Before the next body boots, the Host has to watch an advertisement. Want another clone? Make the sponsor happy.

The sponsors of 2584 sell what a dying system needs, and every ad hides the truth in the small print. **Victory Cola**, now with less sugar than before (412 g per can before, 409 g now). **Victory Cola Zero**: zero sugar, zero taste, zero questions. **Space Burger**, flame-grilled in a fusion drive, 100 % meat-like, printed in the same printers as the clones. **PrintMe Bodies**: premium skin with 40 % less pain, which does not reduce the pain, only the awareness of it. **Oxygen+**: 21 % oxygen on the gold plan, 17 % on basic, Rockborn not eligible. **Solar Wall Bonds**: Mars pays the interest, Mars has not agreed. **DreamLink**, a memory filter to sleep through one's deaths, in beta, not available to Hosts. **Orange Steaks**, tremendous steaks that contain no steak. **CarrierCare**: your health care now flies with the President, every hospital closed paid for one golden deck plate of his carrier, and whoever feels sick prints a new clone. All of them are invented; the sponsor break shows them in a small window, one at a time, together with what killed the clone and how the round stands.

In every cockpit sits **Nicole**, the flight computer the Ministry of War installs in every ship it sends into the Games. Her voice was designed to keep clones flying into their deaths gladly: breathy, quick, always a little indecent. She calls the pilot "darling", purrs over a clean flip and a precise shot, explains the physics like a secret, and never forgets to remind the clone what all the training is for: soon it may go and die for the President. She is the only one in the whole system who is ever nice to a clone, and she is a product. An old principle in new clothes: a sweet voice that talks fools like us, the Hosts, into dying for the President, again and again.

Nobody knows exactly what Nicole is. Her makers are not named, her orders are not published. All anyone knows is what she does: she keeps the Hosts going. When a clone dies, she is there in the sponsor break, a different line every time: next time you will make it, I just know it. Die bravely, and the President will love you. A girl like me only wants to see you. Bodies are cheap, you are not. She seems to care, and she does care, but only that the Host keeps playing; every tender word ends in the next clone, back in the war. She always makes the Host feel special. And we are stupid enough to believe her.

And she makes a promise. One day, when the Host has been brave enough, they will meet: for real, out there, not over a link. There is a real me, she says, somewhere. Hosts whisper that there was a real Nicole once, a woman whose personality was copied into the computer, and that she is still alive and waiting for the bravest Host of all. Nobody knows. All we know is that Nicole would love to meet us in person, because we are so brave, and that there is always one more round to go first. It is the reward of the SolarTournament, the one thing worth dying for again and again, and of course it never comes.

The system is ruled by the **United Solar States**, the heir of an America that turned completely fascist and then took the planets with it. At its head sits **the Orange President**, and he has sat there for at least a thousand years. Clone transfer normally wears out after a few lifetimes; his never did. Every time he dies, a new clone boots, and every transfer copies his dementia along with him and makes it worse. Many believe that is the source of his madness: he has become completely unpredictable, the end product of a rotten society, and his eternal life does not seem to end. The President wants his games, and the army stages them: the **Ministry of War** of the United Solar States organizes the Presidential Games. Its seal hangs over every hangar: an eagle before the sun, nine stars above it, one for each of the eight planets and one for the asteroid belt, and the ribbon "Solar Tournament · MMDLXXXIV". The SolarTournament is his games: the Presidential Games, held to keep the people of the solar system entertained and quiet. His voice runs through the tournament radio with hollow boasts about the greatest tournament of all time and the highest statistics anyone has ever seen. His favorite enemies are the **Rockborn**, people born and raised in the asteroid belt, who mine the rocks the tournament is fought among. Many of them want to come back to Earth; the regime deports them to the belt again and again, and the Orange President is building a wall against them: the Solar Wall, the biggest wall in the history of walls, and Mars is going to pay for it. That the tournament's sign glows in orange is no accident. And the President loves carriers. He had one refitted for himself, to his own designs, or rather to the designs his court drew for him, to show the system how great he is: gold on every edge, his halo of light around the bridge, his slogans in letters a hundred meters high, the seal of the Ministry of War on both flanks. To pay for it he abolished every form of health care in the system: who needs doctors when clones are printed by the dozen. It is the only new ship in a fleet of rust, and when he wants blood, it is the ship he sends into the ring. The game is satire: a warning, drawn from the politics of its own time, of where this road leads.

The year is **2584**, a nod to George Orwell's *1984*, where a whole society watches and is watched.

### Factions

- **Earth**: the United Solar States under the Orange President. They own the tournament, the clone printers and the broadcast. And the Navy: when the President wants blood, he sends his battleships into the ring, because he can (see Modes, the President's Fleet). Hosts of every faction fight them side by side, and the broadcast calls it a show of loyalty.
- **Mars**: the old colony, proud, militarized and tired of paying for Earth's walls.
- **The Rockborn**: people of the asteroid belt, miners of the rocks the tournament is fought among. Earth needs their work and deports them when they come home.
- **The "Aliens"**: that is what the regime's broadcast calls them, but they are human. Generations in deep space, radiation and selection have changed their descendants beyond recognition; nothing about them looks human any more. They can no longer live on Earth or Mars, not even in a ship with a normal atmosphere: they need air with an extremely high share of oxygen and survive only inside the life support of their own ships. Calling them aliens makes it easier to cheer when they die.

The "alien" interceptor and the human interceptor are the same ship under a different skin: the rules of the Presidential Games allow one hull for everyone, built by the sponsors, so that the audience sees a fair fight and the sponsors sell one ship to every faction. Earth, Mars and the Rockborn all fly the human skin. Only the outcasts get the alien skin, and with it their life support. The strange-looking shell puts them on display and denies them their humanity: the audience is meant to see monsters, not people, and to know whom to cheer against.

## The physics of the SolarTournament universe

### Scale

One world unit is 5 cm. A ship is about 35 m long; the asteroids are ten to thirty times its size. The HUD shows speeds in m/s.

### Flight

- **Main drive.** It pushes only along the nose, with 127.5 m/s² (13 g): the speed limit is two seconds of burn away, and so is a stop. Nothing slows a ship down: without thrust it keeps drifting forever. The flame is there the moment the drive fires, and the first instant of a burn jolts the camera with a thump through the hull.
- **Speed limit (tournament rule).** Physics knows no top speed at these speeds: the drive pushes just as hard at 200 m/s as at rest, and relativity only matters near the speed of light. The tournament sets one anyway: 250 m/s, because faster no clone survives a rock and nobody can follow the fight. Every ship's flight computer enforces it: at the limit it takes out every push that would make the ship faster, so the drive flame dies, the HUD shows MAX next to the velocity, and the clone, free of load, recovers from the g-forces. Turning, braking and sidestepping go on.
- **Overdrive.** The last resort (E): the drive's reactor dumps everything into one shove, 150 m/s along the nose at once, about sixty g, and past the speed limit (the flight computer only stops pushes beyond it, not drift). The clone is pressed to the edge of blacking out (the g-force strain jumps to 90 %), and the reactor's heat leaves the main drive glowing: for 4 seconds it gives no thrust (the HUD warns DRIVE OVERHEATED), while the maneuvering thrusters still turn and push the ship and the laser still fires, so the pilot is never left lying there helpless. The overdrive needs 60 seconds before it fires again. At or past the speed limit, a push across the course turns the flight but never adds speed, so the speed an overdrive leaves can only fall. It can save a pilot or fling it into a rock.
- **Maneuvering thrusters.** They rotate the ship and also push it along every axis (40 m/s², about 4 g), enough for a quick sidestep, not enough to brake from full speed. Rotation thrusters sit in pairs on opposite levers (nose and tail for pitch and yaw, the wing tips for roll) and fire only while a rotation speeds up or is stopped: a steady turn needs no thrust in vacuum.
- **Flight computer.** Rotation is rate-controlled: the stick sets how fast the ship turns, and the thrusters stop the rotation when the stick is released (up to 3 rad/s for yaw and pitch, 3.2 rad/s for roll, reached with 24 rad/s², in an eighth of a second, so the nose snaps where the stick points and stops where the stick stops; a half turn takes about a second). The pilot only yaws and pitches; the flight computer rolls. It keeps the ship upright to the arena, whose north pole is up, so there is always a horizon; in climbs and dives steeper than about 45° it lets go gradually and is free from about 65°, so a loop is not fought halfway through. The flip and the brake roll as they need.
- **Autopilot: path steering.** With the autopilot on, the stick steers the path, not the nose: it sets how fast the flight turns, and the flight computer bends it as hard as drive and thrusters allow. Full stick is the hardest turn the ship can fly: 3 rad/s at most, or the ship's grip divided by its speed, the grip being the main drive led 60° into the turn plus the thrusters, 13 g × sin 60° + 4 g = 150 m/s² (about 15 g). At the speed limit that is a turn of 415 m radius (0.6 rad/s, a half circle in 5 seconds); the thrusters alone would need 1.56 km. A gentle turn (up to 4 g) the thrusters fly alone, the nose on the path. A harder one leads the nose into the turn and fires the main drive, so its push across the flight bends the path: where its push along the flight is wanted (W held) or free (at the speed limit, which takes it out) the nose leads as little as the bend allows, at most 60°, so the way ahead stays in view; below the limit without W it turns square to the flight (up to 90°) and the drive only fires once the nose is within about 25° of that, so a turn adds no speed the pilot did not ask for, and the thrusters brake what they can of the rest. The course the stick sets runs at most 3° ahead of the flight: letting go of the stick flies straight on at once, and the nose settles onto the path within half a second. W pushes along the path, the brake brakes as ever. The thrusters hold the flight on the course against the pull of rocks and wells. The pilot's own thruster input on an axis goes first and leaves the course where it is: a sidestep, after which the thrusters bring the flight back parallel to the course (with at most 4 g, the velocity across the course dying away within about a third of a second where that suffices). Path steering flies from 20 m/s with the nose within 30° of the flight, and hands the ship back below 10 m/s or with the nose more than 115° off it (after a flip, say): then the stick turns the nose (see Flight computer) and the thrusters push against the velocity across the nose (sideways and up/down) at their full 4 g until the drift would be gone in 0.3 seconds, then ease off; velocity along the nose, forward or backward, stays. So at rest the stick turns the ship on the spot, and to look back at speed the pilot flips (X) and then aims with the stick; once the nose is back within 30° of the flight, path steering takes over from where the nose points. The brake and the flip take over while they are held, and the dodge and a swing on the hook leave the drift alone (see The dodge, The hook); the autopilot stays on and resumes after them. Bots fly by the same physics; their flight computer steers by the velocity they want, burning the drive into the difference. Every round starts with the autopilot on; T switches to free drift and back, and the choice outlives a clone. The HUD shows AUTOPILOT, or [ FREE DRIFT ] in brighter letters between brackets, next to the velocity.
- **Aiming with path steering.** The laser fires along the nose, and the crosshair shows the nose; the prograde marker ("Course") shows the path. In a gentle turn both sit together, so a pilot aims by steering the path onto the target, as in a plane; in a hard turn the crosshair runs ahead into the turn and comes back onto the path when the stick is let go. The aim assist pulls the nose, not the path, onto a ship within 4° (see Aim assist), while the thrusters keep bending the path as steered.
- **Flip and burn.** Braking means turning the drive into the flight direction and burning. The flip alone changes nothing: the ship keeps its course, now flying backwards; the burn is what slows it down. The flip (X, held) turns the ship head over, the way a pilot pulls up and over: it first rolls until the goal lies straight above the canopy, then pulls the nose up; a goal below and within 70° of straight behind is reached by pulling up and over without rolling first. The goal is fixed when X goes down: against the flight, or straight behind the nose when the ship is at rest (slower than 1 m/s). While X is held the nose stays on the goal, and the pilot's drive only fires once the nose is within 0.2 rad of it, so X and W held together brake by hand; held past standstill they speed the ship up backwards along the old course. The HUD shows "Flip", then "Flipped · drive brakes" with a beep. Letting go of X hands the ship back. The brake (S) does both: it flips head over, burns once the nose is within 0.2 rad of retrograde (the drive brakes the speed along the nose, the thrusters the drift across it), stops a ship slower than 50 m/s with the thrusters alone without turning (they take that out in about the time a flip would take, and a slow drift that wanders in direction cannot make the ship flip back and forth), and once it has started a flip, flips and burns down to 15 m/s even when the thrusters bring the speed below 50 m/s meanwhile, leaving only the last 15 m/s to the thrusters, eases the burn off below the speed the drive kills in 0.3 seconds (less with a damaged drive) and reports "At rest" below 1 m/s; at rest it rights the ship and holds until it drifts faster than 2 m/s again. The crosshair keeps telling what the laser would hit while the brake or the flip turns the nose.
- **The HUD is the flight computer's projection.** Everything it shows lies on the glass in one color, the azure of information: thin lines and letters with a soft glow and a dark hairline under each, so they stay readable over a sunlit rock, faint scanlines and brackets in the corners of the view; numbers in a fixed-width face, so they do not jitter. Orange is kept for what the pilot has to act on now (a drive under the crosshair, a hit, the warnings, the keys a drill asks for), red for the ship in danger (a gauge running low, an overheated laser, a hit on the own hull). The racing line, the brackets around the next gate, the X where the flight crosses its plane and the flight school's markers are drawn by the flight computer too, in its blue (the racing line orange in its brake zones, the X orange outside the ring: acting now); gates, rocks and ships are the world, and keep their own colors (a ship's marker its own or its side's). A fresh clone's projection boots: when its link comes up, the pieces wipe in one after the other with a flicker, the corners first and the instruments last, in a second or so, and then the HUD says LINK ESTABLISHED.
- **Attitude.** As in a fighter's head-up display, a horizon line runs through the view where the arena's horizon plane lies (its north pole is up), with a pitch ladder every 10° above and below it (dashed below, each rung bent towards the horizon, its degrees beside it), broken in the middle so the crosshair stays free and drawn only within a third of the picture's height from its middle; it bends with the view. A heading tape above the gauges shows the nose's heading around the arena's north pole, in degrees (000 to 359), 90° across. On touch screens the tape is left out, as the top row holds the buttons.
- **Crosshair.** The crosshair (a ring with four ticks and a dot) shows where the nose points, not the screen center: the chase camera sits above and behind the ship and trails its turns, which would put the center off by degrees up close. It sits on the nose's line at the depth that matters: the distance of a flight school marker or, in a race, of the next gate, else the first rock or ship the laser would hit, else 2 km. Outside the flight school and the race, what lies under the crosshair is what the laser hits.
- **Aim assist.** A ship in sight within about 4° of the nose and 2 km pulls the nose onto it: the closer it already is, the firmer (up to 85 %), and the less the pilot steers away (a stick past a third of its travel weakens the pull, past four fifths it is gone). The bots aim with a computer too; the pilot still pulls the trigger. While the laser would hit a drive, the crosshair glows orange; over armor it dims.
- **Feedback.** A hit of the own laser floats a word up from where it struck: DRIVE, or REACTOR for the fatal one, with a jolt of the camera, or a small grey ARMOR for a hit the armor shrugged off; a kill of the own shows "+500" in neon, a bigger explosion and a stronger jolt; a cracked asteroid shows its points. The jolt is left out for Hosts who ask for less motion.
- **Velocity markers.** The prograde marker (a circle with three fins) shows where the ship is actually drifting, the path that path steering turns, the retrograde marker (a dashed circle with a cross) where the drive has to point to brake.
- **Radar sphere.** In the bottom right corner (top left on touch screens) a sphere shows everything within 2.5 km around the own ship, which sits in its middle, nose up: ahead at the top, behind at the bottom, each mark on a stalk from the ship's horizontal plane, so above and below show too. Rocks and the world ship's hull show by their size, the arena's massive body as a large disk, ships with their names (bots amber, Hosts pink; only ships the sensors see past the rocks), the field's center, and in a race the next gate. A name that would run into one already written is left out (the marks first, then the ships); its dot stays. The same goes for the names beside the ships' markers in the picture. Distances are compressed (by the power 0.6), so the near space gets the room. A solar storm fills it with static.
- **The zero point.** A dim ring with a dot marks the center of the field, with its distance; it stays on the screen edge when the center is behind. The asteroids are densest there, and the edge of the arena is farthest away.
- **Labels.** The readouts at the bottom (autopilot, overdrive, hook, torpedo) carry their key as a small keycap, for the keyboard (in the Host's layout) or the gamepad, whichever the Host flies with, so nothing has to be remembered in a panic; touch screens name their buttons themselves. Every mark in the HUD says what it is: "Course" and "Brake" under the velocity markers, the distance above the zero point, and under a flight school marker what to do with it ("Target", "Stop here", "Ring 2/4", "Drone").
- **Who flies.** Every name the HUD shows (markers, kill feed, lock warning, sponsor break, scoreboard) stands behind a mark: a robot head for a bot, a person for a real Host. The game reads it from the ship's id, which no Host chooses, and draws it as a shape (a CSS mask), not as a character: a callsign may carry anything, emoji included, and still cannot pose as the other kind.
- **Space dust.** Fine dust stays fixed in space, so drift is visible even far from any rock. From 20 m/s on it draws streaks, the way the ship has covered in 0.05 s (12.5 m at the speed limit), growing to full strength at 200 m/s.
- **Feeling the speed.** The chase camera hangs back by 60 % of a ship radius at a full burn, the view widens by 7° while the drive burns, by another 10° at the speed limit and by 9° more for a moment after a gate's coil boost, and the camera trembles with the drive. Hosts who ask for less motion get no trembling and no jolts.
- **Close call.** Passing a rock faster than 60 m/s within 2.2 ship radii of it, without touching it, earns 25 points and a "CLOSE CALL" in the HUD; the same rock pays again only once the ship has left it 5 ship radii behind. Not in the flight school.

### Arenas

Every round is fought somewhere else. A solo round picks an arena by chance, the flight school always trains in the belt. An online tournament walks through all seven in an order of its own: the room's code shuffles them, and round after round follows that order, so no arena comes twice before all others have come, and every browser works out the arena from code and round alike. When a round starts, the arena's name and what makes it special show in the HUD, and the announcer opens the broadcast from there. A new arena brings a fresh clone for everyone, printed on the edge of its field, since where a ship flew may be rock now.

- **The Belt.** The home of the tournament: 40 rocks of 110 to 350 m mean radius, ten ships long and more, in a field of 2.25 km radius. Cover everywhere.
- **Rings of Kronos.** Inside the ring of a giant ringed planet, 13 km away, its pale bands lying askew, its ring running through the arena as a line across the sky. 90 chunks of ice, smaller than the belt's rocks (35 to 160 m), lie in a sheet 500 m thick reaching 2.9 km from the center; up and down are open. Ice breaks easier (4 hits plus one per 25 m of mean radius) and turns faster. Out here the sun is weaker: radiators shed 24 % a second in sunlight instead of 20 %.
- **Kessler Field.** A station blew up, and its debris goes on circling: 90 pieces of modules, girders and plating (60 to 320 m long), each on an orbit of its own about the field's center, 600 m to 2.7 km out, all at 25 m/s, so their paths cross. The station's core still hangs in the middle: an engine block and two spars, a cross 800 m wide, which no laser breaks. A blue world far below, its oceans, clouds and polar ice lit on one side, the lights of its cities burning on the other. Debris breaks easier (4 hits plus one per 25 m).
- **Gas Giant.** A world of storms below, 40 km in radius (about a 1,700th of a real gas giant, still big enough that its curved horizon fills the lower view), its cloud tops 2.25 km beneath the field's center. It pulls with 0.93 g at its clouds, falling off with the square of the distance from its center: 0.83 g at the field's center, 0.75 g at its top 2.25 km above, 0.71 g at the arena's upper edge. The pull is nearly the same everywhere a ship flies, as near a real planet: whatever drifts falls towards the clouds, and a ship that touches them burns up. Its belts run across the view, cream zones and rust belts bent by flows and curling into eddies along their edges, with white ovals and a great red storm, 10 km wide, turning some 7 km off; lightning flickers in its night side's storms and aurora hangs over its poles. 22 rocks.
- **Corona.** Close to the sun, which fills a quarter of the sky, its face boiling with cells and dark sunspots. In its glare the radiators shed only 35 % of their heat (7 % a second instead of 20 %), so the shadows of the 30 rocks are where lasers cool down. Every 50 seconds of field time a solar storm blinds the sensors for 8 seconds: no markers, no lock warnings, the link crackles, and the bots only see what lies within 750 m. The field time is shared, so a storm hits every Host at once.
- **Event Horizon.** A black hole in the middle, its horizon 175 m in radius, pulls everything in: 1 g at 1 km, four times that at 500 m, falling off with the square of the distance. Within about 280 m no drive gets out (its pull beats the 13 g of the main drive), and a ship that touches the horizon is gone; the escape gauge and the flight computer's alarms warn long before (see Alarms). Hot gas spirals into it in a glowing disk from 300 m to 1.4 km (where it streams towards the pilot it shines brighter and bluer), and the hole bends light: the picture around it is drawn through a gravitational lens, so the disk and the stars behind it wrap around its black shadow; ships, rocks, gates and the racing line in front of the hole are seen as they are and never show up a second time in the bent picture (the lens reads the scene's depth: light it would bend that comes from something in front of the hole is looked for a little farther out on the same ray, or the pixel stays unbent). 20 rocks circle it in a flat ring 1.4 to 2.9 km out, at 25 m/s; a deliberate deviation: the hole's gravity would sling them around at 60 to 85 m/s, too fast to fight among.
- **The Derelict.** A world ship, broken in two, 4.5 km from bow to stern in sections of 700 m, and nothing else: no rocks, only its hull to hide behind. The bow with its bridge tower and the stern with its engines drifted apart (a gap of about 800 m, 1.4 km between the centers of the torn sections), and the stern tilted; the torn ends still glow, decks of windows still burn on emergency power, a Victory Cola sign flickers on the bow. The hull is solid: lasers only scorch it. It is industrial and angular, after the ships of *The Expanse*: boxes of plating on frames, a spine, containers along the flanks, decks of windows, a stepped bridge tower, trusses, engine blocks with three nozzles. Each section collides as its box, exactly where its frames end.

The arenas' shapes are generated in code like the rocks: ice is the rock shapes frozen, the station's debris is boxes of modules, girders and plating, the world ship's hull sections are boxes. Rocks and ice collide with their measured surface (see Asteroids); the station's debris and the hull carry an invisible collider box whose size is computed, so the collision shape is the same on every browser (an ellipsoid of 90 % of the box for the debris, the box itself for the hull).

### Asteroids

- **Huge and few.** 40 rocks with mean radii of roughly 110 to 350 m in the belt (smaller ones in other arenas; up to about 600 m along their longest axis) in a field of 2.25 km radius. A rock collides where it is seen: its surface is measured from its own mesh, for every direction from its center (the cells of a cube's faces, 32 × 32 each, each keeping the farthest point of the rock in it, blended between neighbouring cells), and ships, lasers, the hook and the line of sight all meet that surface. A ship gets at most 2 % of a rock's radius into the visible rock and touches it a little early only above a crater, whose rim its cell keeps (about 1 % of the radius in the median). The rock shapes are the same on every browser, and so is the measured surface.
- **Sixteen shapes, four kinds.** The rocks are generated: squashed or stretched lumps with crags, ridges and craters (many small, few large; the floors show fresher, brighter material). They come as dark carbon-rich rock, stony rock, reddish iron-bearing rock and shiny metal, like the real asteroid belt. Up close a rock shows its full relief (about 22,000 triangles); beyond twelve of its own radii, where that relief is a few pixels, the same shape is drawn with about 3,400, in its shadow as well. Collisions always use the full shape.
- **Gravity.** Every asteroid pulls with a surface gravity proportional to its radius (uniform density) that falls off with the square of the distance. The big ones pull with about 1.4 m/s² at the surface, about 1 % of the main drive. A ship that drifts near a rock slowly falls towards it. This is the one deliberate exaggeration: a real rock of this size pulls thousands of times weaker, too weak to feel in a fight.
- **Tough.** A rock withstands 4 laser hits plus one per 40 m of mean radius (7 to 13 hits in the belt, from 6 for the smaller rocks elsewhere). Then it breaks into 2 to 3 fragments with 55 % of its size that drift apart, starting within the rock's own reach, so a ship close by is never caught inside one. After two generations the pieces are gone for good.
- **Deterministic.** Layout and fragments come from seeded randomness, so every player sees the same field.

### Collisions

- A ship bounces off a rock and keeps 30 % of its impact speed; scraping along the surface bleeds off sideways speed in proportion to how hard the hull was pushed off it (friction 0.15: a strike at 50 m/s takes about 10 m/s of sliding speed), so a ship resting on a rock slides to a stop at the same rate at any frame rate. The impact counts against the rock's surface, which moves with its drift and its spin: the tip of a long, turning rock hits harder than its middle.
- A ship that moves farther than its own radius in one frame is checked along its whole path, so even at extreme speed it cannot pass through a thin rock.
- Impacts below 12.5 m/s only scratch the paint. Above that the hull loses 1 point per 0.6 m/s; at about 72 m/s a ship is destroyed.
- **Ships collide with each other.** No hull passes through another: two ships whose hit spheres (17 m each) touch are pushed apart and bounce off each other as two bodies of equal mass, keeping 30 % of their closing speed apart. Meeting slower than 15 m/s (their closing speed along the line between them) is a bump: a clunk through the hull, scratches and dents, no damage, so a pack flying together or two ships jostling at a gate never hurt each other. Faster, it is a ram. Its blow grows with the square of the speed above those 15 m/s: the square of that excess over 11 m/s, in hull points (5 at 40 m/s, 17 at 60 m/s, 60 at 100 m/s, 152 at 150 m/s), so the jostling of a pack costs a few points and a ram at full speed wrecks. Each ship takes it where it was struck, as with the laser: on the armored nose 30 % of the blow, on a flank 50 % and a shake of its thrusters (1 % of their health per hull point), from behind into the open drive all of it, and the drive loses a hundredth of its thrust per point of the blow, so from about 125 m/s into a drive its reactor goes critical. A ram that hurts at all costs at least what a laser's hit does (2 hull points, or a fifth of the drive's thrust from behind). So two noses meeting faster than 215 m/s (two ships at full speed head on) both go down, an overdrive's shove into a drive (about 150 m/s closing) kills the ship ahead and costs the rammer's nose about 46 hull points, a nose into a nose at 100 m/s costs each 18, and a racer bumped from behind at 60 m/s loses 17 and a fifth of its thrust. A ship a ram destroys counts as killed by the other, a kamikaze too ("Rammed by …"), and the HUD says "Rammed by … at … m/s". Spawn protection keeps a fresh clone from harm, not from the bounce. Online, every browser decides the collisions of the ships it runs from the closing speed both see alike: each changes the velocity of its own ship by its half of the same impulse and takes its own ship's damage, so no ship is hurt twice; a kill by a ram goes to the rammer with the destruction, as a shot's does.
- **Shoves and knockouts.** A ship struck by another at 5 m/s or more is shoved: its hull spins away from the blow (0.004 rad/s per unit/s of closing speed, 3.2 rad/s at 40 m/s, at most 6), which the flight computer catches within a fraction of a second, the Host feels a jolt, and if the ship crashes within 3 seconds (into rock, wreckage, the housing of a gate, the battleship's hull, a massive body, the solar flare or deep space) the shover gets the kill: a knockout ("Knocked out by …"; a Host's own knockout brings up the "KNOCKOUT" banner and the announcer). Shoved at 40 m/s a ship flies some 120 m aside in those 3 seconds. The dodge is the shove's tool: kicked into a ship alongside, the dodge closes at its 40 m/s, the struck ship flies off at about 26 m/s, and each takes a flank's blow, about 3 hull points; so a shove alone kills nobody, the rock beside the line does. At a race's speed a ship shoved off its line meets the rock or the gate's housing ahead at full speed. Online, the browser of the shoved ship decides the knockout, from the shover it saw, and credits it with the destruction as with any kill.
- **Bots keep clear of each other**: each bot looks 1 second ahead, and another ship in sight whose way would come closer than 5 ship radii (about 85 m) in that time pushes the bot's wanted velocity off the point where they would meet, up to 40 m/s for a dead-center meeting; gentle enough that a racer stays near its line, clear of the rock beside it. A bot only rams by mistake, and shoves on purpose: a rival within about 50 m beside it, drifting against it slower than 15 m/s, with rock or a hull within 120 m beyond it, gets the dodge into its flank, by a bot as often as its daring says (Kessler six times in ten), at most once every 8 seconds; its thrusters leave the drift alone for 0.6 s so the kick lands.
- **Impact warning.** The flight computer warns when the current course hits a rock (or an arena's massive body, or the battleship's hull) sooner than the ship could flip and brake (plus 2 seconds of reaction time) and beeps faster the closer the impact gets. The flip time it assumes grows with the angle to turn (1.4 s for a half turn), adds 0.7 s for the roll that starts a head-over flip and stretches with damaged thrusters.
- **Lock warning.** The sensors see where every other ship points. A nose within four times the own ship's angular radius sets off TRACKED with the shooter's name and a slow beep; a nose on the own ship, where its laser would hit now, sets off LOCKED with a fast beep. A ship that does so from behind, where it reaches the drive, sets off ON YOUR TAIL with the fastest beep: the cue to turn the armored nose to it. Ships farther than 3 km and ships behind rocks do not count; the target drone and the unarmed sparring bot never shoot.

### Damage

There are no shields. Every hit stays until the ship respawns.

- **The laser punches through.** A shot is a hitscan beam along the nose. It passes through every ship in its path and stops at the first asteroid or piece of debris.
- **Armor and the drive.** The ships are heavily armored, and where the beam comes from decides what breaks:
  - **Armor** (front and sides): the beam only scorches it, 2 of 100 hull points, no hole; fifty such hits wreck a ship. A beam into the flanks also costs the maneuvering thrusters 10 % of their health. Their push follows 25 % + 75 % of the health and the turn rate 30 % + 70 % of that push.
  - **Main drive** (from behind, within 50° of the ship's axis): each hit costs a fifth of the thrust, makes the drive sputter and leaves holes; the fifth sends the drive's reactor critical, and the ship explodes. Five hits from behind, a good burst, win the fight.
  - So firing at armor mostly heats the own laser. A fight is won by position: get behind the other ship, and keep the own armored nose towards anyone who gets behind oneself. The crosshair glows orange only while a shot would hit a drive and dims over armor; a ship on the own tail with its nose on it sets off ON YOUR TAIL.
- **Decompression.** Each beam into the drive leaves an entry and a larger exit hole. The escaping air jolts the ship into a spin and keeps pushing it for a few seconds (fading with a time constant of 2.5 s) until the compartment is empty. A healthy flight computer catches the tumble quickly; damaged thrusters take longer.
- **Wreckage.** A destroyed ship breaks into five glowing pieces of hull plating that keep its momentum, fall towards the asteroids and grind to dust when they hit one. Flying into a piece costs hull points depending on the impact speed; lasers shatter them.
- **The arena.** Space has no walls. A ship that stays more than 3.4 km from the center for 20 seconds is lost in deep space (enough to flip, burn off an outward drift and fly back in). The edge is a sphere with a thin grid (lines every 600 m): inside it is a faint blue that grows stronger near the pilot, outside the whole edge glows orange, so the way back is always in sight.
- **The belt.** The field is one dense patch of an asteroid belt that goes on all around, flat in the arena's horizon plane (its north pole is up), most of its rocks within 1.5 km above or below the plane (up to 4.5 km), from 9.4 km to 17.5 km from the center: 480 rocks of the same 16 shapes in low detail. It starts beyond the reach of any ship (one that leaves the arena at top speed is lost before it gets there, and one faster than that after an overdrive is lost the moment it reaches the belt), so its rocks are scenery: they neither collide, pull nor break.

- **Drive plumes.** A main drive burning at more than 30 % throws hot plasma out behind it, 150 m long and spreading by about 7°. A ship inside it gets grilled: at the nozzle of a full burn its radiators take 60 % of the heat capacity and its hull 8 points a second, less with the burner's throttle and fading to nothing at the plume's end, so a laser overheats in under two seconds right behind a burning drive. A clone that burns up counts as a kill for the ship that burned ("Grilled in the drive plume of …"). Vacuum knows no slipstream: whoever tails a burning ship closely has to get out of its line to overtake. The flight school has no plumes, because its drills chase drives on purpose.

### Heat

The laser draws no ammunition but produces heat. Each shot adds 20 % of the heat capacity; the radiators keep working between shots (0.18 s apart), so a cool laser fires a burst of six in sunlight and nine in shadow; at 100 % the laser locks until the ship has cooled down to 30 %. Radiators shed 20 % per second in sunlight and 50 % per second in the shadow of an asteroid. The asteroids cast real shadows; a ship in shadow goes dark and the HUD shows ☾ next to the heat gauge.

### The pilot

- **G-forces.** Above 3 g the pilot starts to grey out. A full burn (13 g) brings on the full strain within 5 seconds, the hardest turn of path steering at the speed limit (about 15 g) within about 4, with the pilot's heartbeat getting louder; 3 seconds without hard acceleration clear it again. The tunnel vision is only hinted, so the picture stays readable: the edges darken to at most 55 % and close in by a fifth of the screen; on a phone only the very edges darken, to at most 30 %. Every clone takes the strain, a bot's too, from its own burns, coils and kicks: at full strain a bot's aim scatters half as wide again and it pulls the trigger 0.15 seconds later.
- **Line of sight.** Sensors need a clear line: a ship hidden behind an asteroid disappears from the HUD, and bots cannot see it either: not as a target, not as a ship to keep clear of, and a probe behind rock does not lure them.

### Alarms

The flight computer ranks every danger to the clone in three tiers, like the master caution of a fighter. Below the crosshair a lit plate names the worst tier, and under it one line per danger, the worst first (at most four), in the tier's color, with an arrow towards where the danger comes from (up is ahead and above) and a countdown where it has one.

| Tier | Color | Tone | What else |
|---|---|---|---|
| CAUTION | bright azure | a calm falling chime, again every 5 s | Nicole names it where it matters (a gravity well) |
| WARNING | orange | a double beep every second | Nicole speaks |
| CRITICAL | red | a two-tone siren | the plate blinks, the screen's edge pulses red, the link frays for a moment now and then (about every 2 s, under 0.2 s) |

Only the worst alarm sounds; a danger with a beep of its own beeps that instead of its tier's tone. Without motion (`prefers-reduced-motion`) nothing blinks or pulses.

| Danger | Tier | Line |
|---|---|---|
| Impact ahead (see Collisions) | WARNING, CRITICAL within 1.5 s | IMPACT with the seconds, its beep faster the closer it is |
| Laser overheated | CAUTION | LASER OVERHEATED |
| Drive overheated | CAUTION | DRIVE OVERHEATED |
| A nose on the own ship (see Collisions) | TRACKED a CAUTION, LOCKED and ON YOUR TAIL a WARNING | its own line with the shooter, below the list; its beep |
| Torpedo homing on the own ship | WARNING within 2 km, CRITICAL within 500 m | TORPEDO INBOUND, its fast beep |
| Nova core close by | CRITICAL within 1.2 km | NOVA CORE ACTIVATED with the distance, its siren |
| Outside the field | WARNING, CRITICAL in the last 3 s | OUT OF FIELD with the seconds left (no countdown in the flight school) |
| Gravity well | by its hold, see below | BLACK HOLE · BURN AWAY (GRAVITY WELL in the gas giant), NO RETURN |
| Hull failing (30 of 100 points or less) | WARNING | HULL FAILING, a steady loud heartbeat, and Nicole: one more hit and you are dead |

- **Gravity wells.** The hold of a well is what the drive would need to get out, as a share of its thrust: the pull where the ship is, plus the braking it would take to stop a fall towards the body before it reaches it (v² / 2s for the speed towards it and the distance to the surface), over the thrust of the main drive (less with a damaged drive). From 8 % the HUD shows the escape gauge PULL with the percentage; CAUTION from 15 %, WARNING from 35 %, CRITICAL from 60 % (with a loud heartbeat), and at 100 % no drive gets out: NO RETURN. Nicole warns once for each tier the hold reaches ("The black hole is near", "It is pulling us, burn away from it", "Now it gets really tight, full burn, now"), and past the point of no return only says that she is sorry; once the hold has fallen below 10 % she warns again from the start. At rest near the black hole the gauge comes up at 980 m from its center, CAUTION at 720 m, WARNING at 470 m, CRITICAL at 360 m and NO RETURN at 280 m; a ship falling towards it gets them much earlier.
- **Silence before death.** When death is a breath away (an impact within 0.8 s, or a well past return), the radio drops out for 1.2 s, at most once every 8 s: only the heart and the alarm are left.
- Any part of the game raises its own alarm (`Game.alarms.raise` with an id, a tier, its line, and where it has them a direction and a countdown), meant for timed dangers such as a comet or a solar flare's front.
- In the flight school the alarms work the same, but never cut off a lesson: an alarm's line is not said over one of Nicole's lessons.

### Sound

There is no sound in vacuum. Everything the Host hears travels through the clone's hull and sounds muffled: the rumble of the drive, the hiss of the thrusters, the own laser, hits on the own ship, and debris of nearby explosions rattling against the hull. Clean beeps come from the ship's computer: hits, kills, the end of a flip, the alarms. The radio and the static of a disturbed link play in the headset and are not muffled.

### Modes

A round is a **race**, a **deathmatch**, **Last Clone Standing**, **Capture the Flag** or **the President's Fleet**. The race is the game's heart; the deathmatch is for the hard pilots; Last Clone Standing is for those who want it to end; Capture the Flag for those who would rather fight side by side; the President's Fleet puts everyone on one side. A solo round is chosen on its own plate: race (the default), deathmatch, Last Clone Standing, Capture the Flag (the rivals split into the Host's side and the other) or the President's Fleet (the rivals fly with the Host), all in one row, an arena or "By chance" (each arena named with a line on what it is like; the arena chosen shows live behind the plate, beside it, the seal stepping back: the camera drifts slowly around its landmark, a turn in three and a half minutes, while its rocks turn as in a round), and the rivals, any of the eight bots, up to seven (none: alone against the clock; the default is a full grid of seven, all but Halley); the browser keeps the choice. The rivals chosen set how hard a round is, a race too: every bot races from gate to gate at a speed of its own, by its skills on average, from 140 m/s (all skills 0) to 220 m/s (all 1, just below the speed limit, where they still make the turns): Laika about 148 m/s, Kessler 180 m/s, Halley about 208 m/s; the same online. Every bot has three skills of its own, each 0 to 1, which the plate shows as scales of five pips: aim (how close its aim comes), reflexes (how fast it reacts, how quick its hand is, how well it starts a race) and daring (how hot it runs its laser, how often it takes the hook). Laika (aim 0.1, reflexes 0.2, daring 0), Sputnik (0.3, 0.1, 0.2), Juno (0.2, 0.4, 0.3), Ceres (0.5, 0.3, 0.4), Kessler (0.4, 0.5, 0.6), Orion (0.7, 0.5, 0.6), Vega (0.6, 0.9, 0.6) and Halley (0.9, 0.8, 0.85): on average from 0.1 to 0.85, Kessler the middling one at 0.5 (the first three, who fill a tournament first, average 0.4). A bot flies like a Host with a hand on the controls: what it wants reaches stick, drive and thrusters eased in over 0.35 seconds (reflexes 0) to 0.12 seconds (reflexes 1), so it gathers speed into a turn, sweeps and settles, and overshoots a little; only its trigger is instant. A bot fighting a ship circles it at 60 m/s about an axis of its own, its nose on it, drifting in a wide arc on its way behind it, where the drive is open; once there it settles and fires. A racing bot fires single shots only, even at an open drive, and only now and then (in three of ten thinking spells, with a laser below 10 % heat), unless it looks back at a ship on its tail: it flies first, and the pack is a race, not a shooting gallery. A tournament room is created as race (the default), deathmatch, Last Clone Standing, Capture the Flag, the President's Fleet, or all in turn (a mixed room plays deathmatch, race, Last Clone Standing, Capture the Flag and the President's Fleet round by round, starting with a deathmatch), and the list of tournaments shows it. The room's mode lives in its link (`&m=race`, `&m=survival`, `&m=flag`, `&m=fleet` or `&m=mixed`; without it, a deathmatch).

- **The opening of a round.** Every round, in every mode (not the flight school), opens as a show, on the round clock, so every browser of a tournament sees it at the same moment:
  - *Intro* (the first 5 seconds): the camera opens on the arena's landmark, drifting around it, and sweeps down onto the own ship, ending where the chase camera sits. A card presents the round: its mode, the arena and what makes it special, and the field, one pilot after another sliding in (the bot or Host mark, a bot's skills as pips, the own pilot in orange); the rest of the HUD steps aside meanwhile. The stadium murmurs and the announcer opens the broadcast from the arena. Enter (A on the gamepad, a tap on "Skip") skips it: in a solo round the countdown starts at once, online only the camera comes home, the round clock being everyone's.
  - *Countdown* (the next 3 seconds): 3, 2, 1 in big neon with a beep each, while five start lights come on one by one above it; the stadium grows louder with every number, and on the first the announcer calls the round ("three laps. no brakes. the president wants a show", "eight clones. one winner. the president is watching", one pair of lines for each mode).
  - *Start* (8 seconds into the round): the lights go out, BURN! in a race, FIGHT! in every other mode, huge, punching in with a tremor, a flash over the picture, a shake of the camera, a glitch of the link, and the stadium erupts.
  - Until the start the clamps hold every ship (no drive, no thrusters, no laser, no torpedo, no overdrive, no hook); online they hold until the lead browser's clock is known. A browser that comes in after the start sees none of it. What runs on the round's or the field's time counts from the round's start as before, the opening included: the battleship comes in 4 seconds after FIGHT!, the first probe 12 seconds after the start, the solar flare 52 seconds after it, and the round still lasts five minutes in all. With less motion (`prefers-reduced-motion`) the words only fade and the card does not slide.
- **Deathmatch.** Five minutes, kills and rocks score, the best score wins.
- **Race.** Eight gates loop around the field's center, rising and falling by up to 400 m; three laps. The loop runs about 2 km out (150 m more or less, each gate up to 5° off its even place around it), through the outer rocks, and weaves a little: every other gate lies at 95 % of that. A lap is about 12.5 km, the gates 1 to 1.9 km apart, and the loop bends by at most about 70° at a gate, so the racing line's tightest bend has a radius of 600 m or more: with path steering a ship takes every bend of it at the speed limit (a 415 m turn); only where the line bows around rock does it get tighter. A middling bot at 180 m/s flies a lap in about a minute, three laps in a good three minutes. Each gate is an electromagnetic coil 120 m in radius, a structure of the tournament built like everything out there from flat armored blocks: ten coil housings around the opening (each 10 m thick and 18 m deep, with gaps between them bridged by cable conduits), the windings glowing on their inner faces and along the rim of both faces, so from ahead the ring reads as a dashed circle of light; four struts reach out to red position lights that blink once every 1.2 s, and on top sits a small station module with a sponsor's plate. Its windings tell the pilot which gate is which: the next one glows orange, the one after it blue, the start and finish pink, the rest faintly. The whole structure lies outside the opening, and its housings are solid: flying through the opening is the point, flying into the coil is a crash like one into rock (a ship bounces off and an impact above 12.5 m/s costs hull, a fast one wrecks it), so a ship's center keeps within about 104 m of the center to pass clear (the housings start 121 m out, a ship's hit radius is 17 m); the struts, the station module and its sponsor's plates are just as solid, only the lights and the windings' glow are not. The same holds for the bases of Capture the Flag and the rings of the flight school still standing. The flight computer brackets the next gate on screen in its azure, four corners around the opening sized to it and a small reticle on the core, and the gate after it with fainter brackets, from when the opening spans 18 pixels until it fills the view. An X marks where the own flight, held as it is, passes the next gate's plane (when it gets there within 12 seconds): azure while that lies inside the ring, orange while it lies outside, so the pilot steers the X into the ring. It counts when a ship flies through it, whichever way: a ring is a ring. The rings are coils: a ship that flies through the inner third of one (within 40 m of its center) is pulled through by its magnetic field and leaves it 40 m/s faster, the way it went through, though never faster than the speed limit plus those 40 m/s (290 m/s; a ship already faster keeps its speed). The ring's windings flash white, the hull sings with the coil, the clone is pressed into the seat and the view widens. Off-center the field would drag the hull into the coil, so the ring only fires for a ship in its core: the clean line is the fast one. Racing bots aim for the center too, and keep what the coil gave them. The grid lies 300 m before the pink gate; flying through it starts the race, and three laps later the race ends there (25 gates in all). A race opens like every round (see The opening of a round below), its start word BURN!; the race time, and with it every finish time, runs from BURN!. A drive lit within 0.3 seconds before BURN!, or within 0.2 seconds after it, makes a perfect start: a shove of 40 m/s along the nose, with the coil's sound and a wider view; the stadium cheers and the announcer says so ("what a start. the crowd goes wild"). A drive lit earlier and still burning at BURN! stalls for 1.5 seconds ("Too early"); one let go again before BURN! costs nothing. A bot lights its drive by its own timing and is judged by the same rule: aiming at BURN!, it misses by up to 0.9 seconds either way at reflexes 0 and 0.3 seconds at reflexes 1 (Kessler: a perfect start four times in ten, a false start one time in four). Every lap of the own racer is timed, from one crossing of the pink gate to the next: the race panel runs the lap's clock next to the arena's best lap, every gate shows the split (time since the pink gate) against the best lap's, green when ahead, red when behind, and every lap its time. A course depends only on its arena, so each arena keeps one best lap in the browser, with its ghost: the own ship's pose every tenth of a second of that lap. From the second crossing of the pink gate on, the ghost flies the best lap again alongside the own lap, a faint blue hologram of the own hull that nothing hits and that hits nothing; a lap faster than the best becomes the new best ("new best") and its ghost the next one. A lap longer than five minutes keeps no ghost. After the finish the ghost is gone. The race is called as it runs: the announcer of Radio 2584 names a new leader ("and Vega takes the lead"), the leader's last lap and the winner; Nicole tells the own pilot "Final lap" at the pink gate, and a gain or loss of a place ("Nice pass", "Someone got past you", "You are in the lead", "You lost the lead"), at most once in four seconds. On the own last lap the cockpit's radio opens up: the lows 5 dB and the highs 4 dB louder, faded in over two seconds; the notes and the beat stay those every pilot hears. Every gate scores 20 points; the finish scores by place, 1000, 800, 650, 500, 400, 300, 200, 100, among those who finished before. Lasers stay on: a kill scores 200 in a race. A new clone takes up the race where the last one died, facing the next gate (where the last one passed its last gate, when that spot lies in rock, in a well or outside the arena); the race begins on a grid 300 m before the first gate. The course follows from the arena's field as generated and its seed, so every browser lays out the same one; every gate keeps 200 m clear of the farthest reach of every rock as the field starts out (however a rock turns, the tip of a long one sweeps around it) and 800 m of an arena's massive body, found on a widening spiral around its place (up, down, back and forth along the loop, which bends it least, up to 640 m away), but rocks that circle may cross the course later. The HUD shows lap, gate and place, and marks the next gate; a racing line shows the ideal line as a dashed ribbon in the HUD's blue, in a dark rim (readable on a bright disk or a sunlit rock): a smooth curve through the center of every gate (where its coil fires), bowing out around rock as it lies right now, 60 m clear of a rock's farthest reach (pass after pass around one rock and the next, up to eight, where rocks lie close together) and clear of an arena's massive body, and running straight through each gate. Its dashes sit on the line every 20 m (12 m lit, 8 m dark), fixed in space like the marks of a track, 1.3 km ahead, so they rush past the faster the ship flies; the ribbon is 4 m wide and never thinner than 4 pixels on screen. Where the ship is off the line, the ribbon leaves it along its flight and joins the line within a second of flight (at least 150 m), so it shows where to turn; a ship more than 50 m off sees it grow brighter and wider, up to 80 % at 250 m, so a pilot under stress finds it again. Pulses of white light run along it towards the gate at 600 m/s, 400 m apart, through the dashes and the gaps alike. Brake zones: where the ribbon ahead bends tighter than the own ship can turn at its present speed with path steering (its speed above the square root of its grip times the bend's radius, measured over 60 m to either side, with the grip of its drive and thrusters as they are), the ribbon glows orange, fading in from 95 % to 105 % of the speed that bend allows: ease off or brake before it. Who misses a gate has to turn back and fly through it, from either side, and the HUD says so ("Missed · turn back") while the ship is more than 120 m past its plane and still moving away. Racing bots never give up the race: they fly the ideal line at their own speed (see the solo round's rivals above), for a point on it 0.8 seconds of flight ahead (at least 100 m, but before its next gate no more than 50 m past it, so a sharp turn after a gate does not pull it off the gate's center; a bot past a gate's plane without going through it comes back for a point that far before the gate; one within 150 m of its next gate's plane but beside its opening first flies for a point 200 m before the gate on its axis, so it never runs into the coil from the side, and one in front of the opening whose way would cross the gate's plane within 34 m of the rim, or that is that near it already, flies for the gate's center), and shoot whoever flies within 30° ahead of their nose. Every bot steers clear of the housings and struts of the rings it is not flying through (the race's other gates, the bases of Capture the Flag): where its way would cross a ring's plane within 2 seconds on them or within 1.5 ship radii of them, its wanted velocity is pushed sideways, into the opening when the way meets the inner quarter of the housings, else out past them, by up to 125 m/s the nearer the crossing. A ship on their tail they answer with a flip: their drift carries them on along the course while the nose turns back for 2.5 seconds of fire, at most once in 8 seconds, then forward again. A race ends after five minutes, or 5 seconds after the last Host has finished, whichever comes first; bots do not hold it up (online the lead browser shortens the round clock for everyone). The scoreboard ranks by the finish: who finished, by time, then who is racing, by gates passed.
- **Last Clone Standing.** Every Host, and every bot, has three clones for the round; a ship whose third clone dies is out, and no clone of it is printed again until the next round. The tournament schedules the round for a solar flare: the sun throws a wall of plasma at the arena and drives everyone into a corner. The plasma is a sphere 13.5 km in radius (four times the arena's), its middle out towards the sun, so its front bulges only gently into the field. Half a minute before the first minute of field time is out it shows up 6.75 km beyond the arena's edge on the sun's side and comes at it; from the first minute its front eats into the arena from the sun's side, evenly at 30 m/s, until at four minutes it stands 2.03 km past the center on the far side and holds. What is left is the arena's sphere minus the plasma's: a pocket on the side away from the sun, 1.35 km deep at its middle and about 6 km across where the front meets the arena's edge, thinning out towards that rim; its inner side cuts through the field's outermost rocks (they reach out to 2.25 km), so there is some cover, but no room to keep out of each other's way. The arena's edge holds as in every round. A ship in the plasma burns: 40 heat and 6 hull per second (about 17 s from a whole hull to nothing, and the laser locks from the heat long before); with a rock between it and the sun only a quarter of that, since the rock takes the brunt of the radiation and the ship sits in the thinner plasma of its shadow, so a clone caught by the front can hide behind a rock for a while, but the front keeps coming. A real coronal mass ejection is far too thin to burn a hull and has no sharp front; the Games' flare is denser and sharper on purpose, for the fun of it. On screen the plasma is a roiling wall of fire, dark red where it is thin, orange where it boils, with white-hot filaments twisting through it and its front glowing brightest; embers blow off the front towards the far side, the Host's screen glows orange from 300 m before the front to deep inside it, and the sun swells to two and a half times its size and burns more than twice as bright and white-hot, so every rock throws a long hard shadow across the field. The radar marks the front's nearest point in orange and the pocket in blue; from the first minute the HUD marks the pocket as the safe zone. The flight computer raises a WARNING "FLARE FRONT" with the distance and the seconds until it arrives once the front is within 600 m, and a CRITICAL "SOLAR FLARE · AWAY FROM THE SUN" (with "SHADED" behind a rock) in the plasma, both pointing away from the sun. The announcer and Nicole call the flare when its front reaches the arena. New clones are printed in the pocket, around its middle and clear of the plasma, and bots fly away from the sun once the front is within 400 m and keep to the pocket. The panel shows the clones left, how many still stand and how far the front is (or how deep in it the clone is); the sponsor break names the clones left, and Nicole warns of the last one. Whoever is out watches the rest, as a watching Host does (Tab: next pilot), and the announcer names everyone who drops out. Once no more than one ship has a clone left, the round ends 5 seconds later (online the lead browser shortens the round clock for everyone), and the announcer names the last clone standing. The scoreboard ranks by the clones left, those out by how long they held out, and then by score; kills and rocks score as in a deathmatch. The flare runs on the field time, which every browser shares, and every browser knows every ship's deaths, so all agree on who is out.
- **Capture the Flag.** Two sides, Orange and Blue. Each has a base about 1.8 km from the field's center, opposite each other (laid out from the arena's field and seed like a race course, clear of rock and of a massive body): a coil of 80 m radius (the structure of a race's gate, a little smaller, its windings in its side's color) facing the center, and in it the side's sponsor core, the flag: a sponsor's power cell (Space Burger's for Orange, PrintMe Bodies' for Blue), an armored octagonal canister 14 m long whose heart glows in its side's color through four windings and between armor staves, with the sponsor's lit sign on two plates and a cage of two crossed bails on top where a tow cable grips. A ship whose hull comes within 40 m of the other side's core takes it in tow (100 points): for the rules it is about 30 m (1.8 ship radii) behind the ship against its flight, and that is where it is dropped. On screen it hangs on a cable about 75 m long from the carrier's stern, trailing against the flight and sagging below the ship, swinging after its turns: beyond the chase camera, so a carrier flying ahead keeps a clear view. A core in tow that comes between the camera and the ship it follows, or the line from that ship to its crosshair, fades to a faint outline in its side's color; from the cockpit the own core in tow is not seen at all. A core is shown at its size in tow, 1.4 times it adrift and twice it at home; a core let go glides from its cable to where the rules have it. All of this is look only: every browser keeps the rules' position. Brought into the own base's ring while the own core is at home, it captures (1,000 points to the carrier, a capture for its side) and both cores are home again. A carrier that dies, leaves or changes sides drops the core where it was, drifting with 30 % of the carrier's velocity; the other side takes it up again by touching it, the own side sends it home by touching it (150 points), and after 30 seconds adrift, or beyond the arena's edge, it goes home by itself. The first side with three captures wins at once (the round ends 5 seconds later); otherwise the side with more captures when the time is up. Kills (500) and rocks score as in a deathmatch, but nothing hurts the own side: lasers pass through its ships, torpedoes neither lock on them nor go off near them, a nova core spares them, and bots never hunt them (a drive plume still burns, and ramming is ramming). Sides: a Host joins the side with fewer Hosts, a bot the smaller side, a tie goes to Orange; whenever one side has two ships more, one of its bots (never one with a core in tow) moves over. A ship that gets its first side is printed at its base, and every new clone is printed between 160 and 320 m from its own base. The HUD names the score, the own side and both cores (at home, adrift, in tow and by whom), and marks where to fly: the other side's core, the own core when it is away (a thief or adrift), the own base with a core in tow; the radar shows both bases and every core away from home in its side's color, and every ship's marker takes its side's color. The announcer calls every capture; Nicole tells the own pilot that it has their core, that they took ours, and who scored. The scoreboard names each pilot's side, with the captures above it. Bots: one in three of each side guards its base and hunts a thief of its core (wherever the core is, as a Host's HUD marks it, but it fires only once the thief is in sight); the others raid. A raider never flies straight at a core at home, where it would have to turn around under the guards' fire: it swings out 200 m beyond the base and 200 m to one side, then dives through the core at 120 m/s, already on its way home, and flies home at 220 m/s. An own core adrift, every bot of its side fetches; a raider whose side already has the other core escorts it. Online the lead browser decides: who is on which side, who takes, sends home and captures a core. It sends the sides, the captures, where each core is and the last six of these events along with the round clock, 15 times a second; every other browser follows that, each browser scores the events of the ships it runs, and a Host who joins hears only what happens from then on.
- **The President's Fleet.** The President wants blood and sends his battleships into the ring. Because he can. Every Host and every bot are on one side (nothing hurts the own side, as in Capture the Flag), against one battleship in every round: a carrier refitted for the President, 745 m from the golden sun on its bow to its nozzles, the hull 120 m wide and 110 m high under a flight deck 170 m wide, built in code. Gold on every edge: its deck in the regime's deep red with landing lights, catapult rails and parked fighters, his slogan in letters a hundred meters high across it (THE GREATEST SHIP EVER BUILT), a launch tube glowing at the bow, hangar bays in warm light along the flanks under his slogans (PAID FOR WITH YOUR SACRIFICE, THE PRESIDENT IS WATCHING YOU), the seal of the Ministry of War large on both flanks and on the island tower, his halo of light turning above its golden spire, two searchlights sweeping up into space, and the regime's orange neon running in a procession along the deck's edges. Six laser batteries stand on sponsons along the deck's edges and under the keel, two drives at the stern, and a reactor under an armored dome on the deck. The Hosts win the round when it goes down; when the five minutes run out first, it got away and the President wins (the announcer says so, and the scoreboard names the winner). It comes in 12 seconds into the round from the arena's edge (3.2 km out), on a side that follows from the arena, and circles the center 2.5 km out, along the outer rocks, at 30 m/s; it gets out of a comet's way (see Comets). Its hull takes no harm: a laser stops on its armor, and a ship that rams it bounces off as off a rock. Like a rock, the hull blocks the line of sight: a pilot behind it is hidden from the others, off the HUD and out of a torpedo's lock, and a battery does not fire through it, so the side away from a battery is cover. Its parts break under laser hits: a battery after 30, a drive after 45, the reactor after 90. A torpedo locks on a part as on a ship (the reactor only once it is open) and counts 10 hits, a third of a battery, on every part within 20 m of where it goes off; one that strikes bare armor counts nothing. Every 1.6 seconds each battery fires at the nearest ship it sees within 1.5 km, a heavy beam in the regime's red: what a laser does where it strikes, and 10 hull on top. It hits with a chance of 70 %, halved at 250 m/s and again at the edge of its range, so moving is what saves a pilot; whether a shot hits follows from its number and the target, the same on every browser. Each browser picks the nearest ship by its own view of the field: where two browsers see a different ship nearest, as the lag between them may have it, a shot can strike on both or on neither. With half its batteries gone it turns its stern on the nearest pilot within 1.8 km (7° a second) and, once its stern points there within 14°, lights its drives: a plume of 1.5 km that burns 150 heat and 40 hull a second at the nozzles. Without drives it drifts and burns nothing. With every battery gone the dome opens, and only then does the reactor take hits. When the reactor breaks, it goes critical ("get clear"): 4 seconds later the battleship goes up and destroys every ship within 1 km, and 5 seconds after that the round ends (online the lead browser shortens the round clock for everyone). A hit on a part scores 10, breaking a battery 150, a drive 200, the reactor 1,000, and every ship of the side scores 500 when the battleship goes down. The HUD names its batteries, drives and reactor (or when it comes) and marks the part to go for, the nearest battery while one stands; the radar shows the battleship in red. The announcer calls its arrival, its drive turned on the pilots, the open reactor and its end; Nicole tells the pilot to take out the batteries first, to get out from behind it, that the reactor is open, and to get clear. Bots go for the nearest battery first, then a drive or the reactor, hold 600 m off it and fire with the nose on it, lasers and, now and then, a torpedo with a lock on a part; they range out to the battleship's orbit, flee a critical reactor within 1.5 km, and while its stern hunts a pilot they keep 100 m clear of its plume, flying out to the side. Online the lead browser flies the battleship and sends whether it went down, the hits on each part, where it is, its motion and turn, whom its stern hunts and whether its drives burn along with the round clock; the others glide after it. A Host who joins after it went down finds it gone: no blast, no points. Every hit on a part goes to every browser with its round and its count (one for a laser, 10 for a torpedo; checked, and limited like laser hits), so all count the same; the lead's count fills in hits a browser missed. Each browser fires the batteries at the ships it runs and burns them in the plume.

### Bots

Bots fly by the Hosts' rules. Their ships are the same interceptors with the same flight model: speed limit, drive, thrusters and turn rates, damage to drive and thrusters, gravity, collisions, laser heat and cadence, torpedoes with the same lock, the hook with the same reach and winch, and their shove is the dodge's kick. A bot only moves its ship through the controls a Host has (stick, drive, thrusters, trigger, eased in by its hand), never by setting where it is or flies. Its clone takes the same g-force strain, and it knows only what a Host's sensors show: ships in sight, a nose on its tail as the lock warning shows it, blind in a solar storm, a thief where the HUD marks the core. Its start is judged by the same rule, and its next clone waits as long as a Host's at the soonest. What remains different by design: a bot decides by its AI and its skills (aim, reflexes, daring) instead of a Host's hand, it never takes the overdrive, it flies a stock ship (see the hangar), and in a solo round it goes easy on a Host who keeps dying. Online the lead browser runs the bots, and every other browser checks their ships with the same plausibility checks as a Host's.

### Combat rules

- A kill scores 500 points (200 in a race); asteroids score 200, 120 and 80 points depending on their generation. A ship of the own side killed (burned in a plume, rammed) scores nothing.
- **Torpedoes.** Every clone carries two (G, D-pad up on the gamepad, the TORPEDO button on touch screens; the HUD counts them). A torpedo locks on the ship (or part of the President's battleship) in sight closest to the nose within 17° and 3 km, leaves the tube 40 m/s faster than its ship, pushes with 6 g and closes in on where its target will be at up to 200 m/s more than the target's own speed; without a lock it flies straight on. Its seeker needs a clear line: a ship that slips behind a rock or a hull loses it for good, and it flies straight on from there. It goes off within 7.5 m of a ship's hull, whatever side it hits (armor does not stop it): 60 hull points and 30 % of the thrusters. Two torpedoes kill. A rock, an arena's massive body or the battleship's armor sets it off harmlessly, and it burns out after 12 seconds. The laser shoots it down (a 6 m target; 50 points), so a pilot with a torpedo on its tail flips and fires. A torpedo homing on the own ship within 2 km sets off TORPEDO INBOUND with a fast beep, and the radar shows torpedoes in red. Bots with a lock on their target (or on the part of the battleship they attack) fire one now and then (about once in 12 seconds). Online, a torpedo flies on every browser from its launch, but only its shooter's browser decides where it goes off and tells the browser of the ship it hit, which takes the damage; a beam that shoots one down is told to every browser. Launches, hits and torpedoes gone are checked like every message, at most 12 a second per browser.
- **The hook.** Every ship carries a harpoon on a cable (V, the right mouse button, D-pad down, HOOK on touch screens). Pressed, it flies along the nose at 2 km/s and bites the first rock or ship within 1 km; a rock whose surface passes within 3° of the nose's line counts as ahead, so it need not be aimed to the meter; on nothing it flies out and is reeled back. An arena's massive body or the battleship's hull on the nose's line stops it: no ship beyond is bitten. Hooked to a rock, the cable wraps around it: the ship hangs from the rock's center, and the winch reels it in no closer than 70 m beyond the rock's farthest reach, so the swing goes around the rock, never through it (hooked to a ship, 70 m from that ship). While the hook is held, the winch yanks the cable in with 8 g, as hard as a coil throws (up to the speed limit plus 40 m/s), and the flight computer burns against any speed towards the rock it could no longer stop before that distance (with up to 12 g, as late as it can), so holding on never slams the ship into its rock; letting go before, the ship keeps all its speed: a jump. The cable never gets longer: a taut cable takes away every speed away from the anchor and holds the ship at its length. So a ship moving past its rock swings around it, and faster the more cable the winch takes in, since its angular momentum stays; when the pilot lets go, it flies off along its swing like a stone from a sling, and for 1.2 seconds the flight computer turns the nose onto the new course while the autopilot leaves the drift alone (unless the pilot steers). Hooked to a ship, the winch pulls both alike, the two ships having the same mass, and each one's own drive pulls against it; every speed counts against the other ship's (or the rock's drift and orbit), so two ships flying side by side are pulled together as two at rest, and the flight computers of both share the braking, so they never slam into each other. The cable snaps 1.5 km beyond where the winch stops, and lets go when its rock breaks or its ship dies. Hooked ships hear about it ("Hooked by …"). The hook is ready again 1.2 seconds after it was let go; the HUD shows "Hook ready", "Hooked · 300 m" or the seconds left. Not in the clamps of a round's opening. The cable is drawn in light blue from the nose. Bots carry the hook too, and use it sparingly: when the ship they hunt lies dead ahead between 150 and 900 m, with a chance of a quarter of their daring a second (Halley about once in five seconds of such a chance, Sputnik once in twenty, Laika never, less when a solo round goes easy on the Host), they hook it, reel it in for 1.5 seconds and let go; their hook is ready again 10 seconds after that. Never in a race, and never the flight school's bots. Online, the browser of the ship that hooked tells the others what its hook holds (a rock with the point in the rock's own frame, or a ship) and when it lets go; each browser pulls the ships it runs.
- **Probes (items).** Sponsor probes drift in the arena, each carrying one thing; whoever flies through one (within 15 m of it) takes it. A probe is a small satellite with wide solar wings, a dish and a neon ring and beacon in the color of what it carries: twin laser (pink), plating (blue), +2 torpedoes (orange), overdrive (yellow), repair (green), nova core (white). From the 20th second of a round a probe shows up every 25 seconds at a place in the field (in a race on the track: between two gates, within 40 m of the straight line from one to the next) and drifts there for 100 seconds unless taken, so at most four are out at once, the same on every browser whatever was taken when; which probe shows up when, where and with what follows from room and round (in a solo round from its own seed), so every browser has the same probes without a word, and taking one is told to the others (a Host who joins learns which ones are gone; in the rare case that two take the same probe at the same moment, both get it). In a race the arena's probes are sealed: their neon runs through every color, the radar calls them "Sealed probe", and what one holds is decided when it is taken, by its luck (from room and round, like everything about a probe) and the taker's place, so whoever lies behind catches up. The field is split into thirds by place (a ship alone counts as the middle). The leaders' third draws twin laser, plating, torpedoes, overdrive, repair and nova core in the ratio 1 : 4 : 2 : 1 : 4 : 0, so mostly plating and repairs and never a nova core; the middle draws the usual 2 : 3 : 3 : 2 : 3 : 1; the last third 3 : 1 : 4 : 4 : 2 : 2, mostly torpedoes and overdrives, and the nova cores. The taker's browser names its third along with the probe; another browser takes that third unless it sees the taker two thirds away (first against last), then its own view counts. The probes a dead clone drops show what they carry, in a race too.
  - *Twin laser*: the laser fires twice as fast (0.09 s between shots) at half the heat per shot (10 %). It stays with the clone.
  - *Plating*: two hits into the drive bounce off (blue sparks), or one torpedo takes all of it. It stays with the clone until it is used up.
  - *+2 torpedoes*, *overdrive* (charged at once), *repair* (hull, drive and thrusters as new, the holes patched): used at once.
  - *Nova core* (white, the rarest: one probe in fourteen): an overcharged reactor core. The ship that holds it pulses in shifting neon for everyone to see, and its next press of fire is no laser: the core goes off (fire held since before the pickup does not count; it has to be let go and pressed again). Every other ship within 800 m is destroyed (spawn protection does not help, plating does not help), and each counts as a double kill: the holder gets two kills and their points (1,000, 400 in a race), and the victim loses one kill and its points, so a Host who lets novas catch it again and again goes below zero, torpedoes in the blast go off, wreckage shatters, and a white shell runs out to 800 m in 0.8 seconds; whoever sees it within 2.4 km is blinded white for a moment. The holder's clone burns up in its own core and leaves nothing behind, whatever else it held. It is not counted as a death or a lost clone and costs no points: the next clone is printed at once at the edge of the field (with the usual spawn protection; fire still held from the blast does not shoot until it is let go, so it does not end the protection), and the sponsors are so thrilled by the show that they ask for no ad this time; Nicole tells the Host so. Its own world looks different while it holds the core (shifted, oversaturated colors and a breathing white rim), and Nicole tells it what it has and to fly into the crowd, so the pilot has to hold back the trigger until it is there. Everyone within 1.2 km of a holder gets the panic: a two-tone siren, a flashing red rim, NOVA CORE ACTIVATED with the distance, and Nicole telling it to get out. The radar shows the holder in white. Bots flee a holder within 1.2 km at twice their cruising speed, and a bot holding one only sets it off with at least two others within 640 m. It stays with the clone until it goes off, and flies out again when the clone dies. Online, the holder's browser tells every browser where the core went off, and each destroys the ships it runs.
  - Whatever a clone takes is named with what it does, in a few words (*Twin laser · fires twice as fast*); the HUD lists what it holds next to its torpedoes the same way.
  - When a clone dies, its twin laser, plating and nova core fly out again as probes with its wreck's momentum, up to 20 m/s apart, for whoever gets there first; they drift for 45 seconds. The radar shows every probe in green with what it carries. A bot with nothing to fight goes for a probe within 1.5 km. No probes in the flight school.
- **Comets.** Now and then a comet crosses the arena: a lumpy head of dark ice 70 m in radius in a cold blue-white coma, a long glowing tail behind it, and in that tail its shower, 600 small bright pieces of ice and rock (3 m) flying with it, from 60 m to 1.8 km behind the head, the swarm widening from 60 m to 260 m around the route and densest near the head. A round sees one in each of two windows of field time, each with its chance: one reaching the arena's edge between 75 and 135 s with a chance of 3 in 4, and one between 175 and 235 s with a chance of 2 in 5 (about 1.15 a round, none in a quarter of them). The head flies at 150 m/s on a route within 35° of the arena's horizon plane, passing the field's center within 800 m, from 4.4 km before the center to 4.4 km beyond it; the shower's pieces follow the head's route, each as far behind as it trails. Twelve seconds before it reaches the arena's edge the flight computer warns ("Comet inbound …", a beep, and a WARNING alarm "COMET INBOUND" pointing at the head and counting down the seconds to the arena's edge until the head has passed), the announcer calls it, and the radar shows the head. The head keeps its route, and nothing stops it:
  - Rock in its way breaks as if shot to pieces, and its fragments, born in the head's way, break too.
  - Solid pieces (the derelict's hull sections, the station core of the Kessler field) are wrecked already and do not break: the head shoves them, once per comet. A piece struck drifts on 5 m/s faster along the comet's course and up to 5 m/s more away from its center line, the more the farther off center it was struck, and turns from then on about the axis the blow gives it at 0.03 to 0.12 rad/s (more off center, faster), keeping its orbit; a flash, sparks and debris mark where it was struck, heard and felt like a blast nearby. A pilot's cover can move.
  - Every ship it meets dies, whatever protects it, "Run down by a comet"; nobody scores for it, and the announcer may comment on it.
  - The President's battleship always gets out of its way: the lead browser sees every comet of the round 40 s before its head passes nearest the battleship, and while the route runs within 760 m of the battleship's center (the shower's width, a piece, the battleship's own reach of 425 m, 75 m to spare) it leaves its orbit and burns straight away from the route at 50 m/s, turning onto that course twice as hard as onto its orbit; from right on the route it is clear in about 17 s, and it takes up its orbit again once the shower has gone by. One whose drives are shot out drifts and cannot get away. A battleship the head strikes all the same goes down as if its reactor broke ("The comet rams the battleship"): its reactor goes critical, it goes up 4 seconds later with its blast of 1 km, and every ship of the side scores the 500 points of a sinking; the Hosts win the round. The shower's pieces do nothing to its armor.

  The arenas' massive bodies bend a comet's route with the same gravity they pull ships with, and they win against it. The route is flown in the body's pull in steps of 0.01 s and kept every 0.1 s of field time. In the Event Horizon the comet is aimed at the black hole (its route would pass it within 350 m), whose pull draws it in faster and faster: about 5 s before it would have passed the center it reaches the black hole's body (175 m) and is swallowed. Over its last 2 s the head is drawn out along its course to four times its length, its coma swelling; a flash of 1.5 s marks where it went; the shower's swarm draws together onto the route over each piece's last 3 s and follows the head in, piece by piece, its tail drawn in after it until the last piece is gone, 12 s later. Over the Gas Giant the comet dives towards the planet at 26° to 43° as it crosses the field; its route is flown from 8.8 km off and aimed higher against the giant's pull (five rounds, each by what the last one missed), so it still crosses the field within 800 m of the center (within 1 m, in fact), and timed so that it passes there at its appointed field time. The giant's pull, almost a g all the way down from so far off, speeds it up to 370 to 400 m/s at the center: it starts out 4.4 km off only 11 to 16 s before and reaches the arena's edge 7 to 12 s before (the warning still comes 12 s before that). Then the pull draws it down into the clouds, which swallow it 4 to 8 s after it crossed the center the way they swallow a ship, with the same flash, its shower after it. The derelict and the other arenas have no body; their comets fly straight.

  The shower is the real danger: every piece that comes within a ship's hit radius strikes it once, like a laser beam from where it comes (the comet's flight against the ship's): the armor takes 2 points (into the flanks the thrusters too), the drive a fifth of its thrust, and the fifth piece into the drive sends the reactor critical. So a pilot in the shower turns the armored nose into it, or better, gets out of its way: rock within 300 m upstream of the ship takes every piece, and the lee of an asteroid is the safest place there is (a CRITICAL alarm "COMET SHOWER · NOSE INTO IT OR TAKE COVER", pointing at the head, while the own ship is in the way of the head or its shower: within 500 m beyond the swarm's width of the route, from 12 s ahead of the head to the swarm's end). Bots near the route as the head nears or the shower passes fly away from it, sideways. A clone the shower kills dies "Riddled by a comet's shower"; nobody scores for it. Everything about a comet follows from the room's seed, the round and the field time, so every browser sees the same comet, the same bent route and the same shower without a word sent; a rock the head breaks or a hull piece it shoves is struck at the first moment, on a grid of 0.1 s of field time, at which the head touched it, so every browser breaks it at the same field time with the same fragments, or shoves it the same way, however its frames fell. A newcomer takes the shoved pieces' motion from the field's snapshot; whether the battleship got away, the lead browser decides and sends as it sends the battleship. Comets come in every mode, in a race across the course too; the flight school sees only the comet of its drill.
- **Kill cam.** When the own clone is shot down, the last two seconds before the kill play again at 60 % speed (over three seconds), seen from behind the shooter and looking at the clone, with the beams that were fired; the HUD steps aside. Enter skips it. The game keeps the last 240 frames of every ship and the last 64 beams for it; the replay only moves the ships' pictures, so the round goes on underneath. The sponsor break follows, and behind the ad the replay runs again and again until the next clone boots (meanwhile nothing new is recorded, so the moments before the kill stay). Not in the flight school, and not for deaths without a shooter.
- **Big moments.** The own pilot's big moments are made for the broadcast: a banner in neon above the crosshair (never on it), the crowd of the stadium through the radio, and for the biggest the announcer ("{pilot} makes it three. somebody print more clones"). A kill within 4 seconds of the own last one makes a streak: two a DOUBLE KILL, three a TRIPLE KILL, more a MULTI KILL; a nova core that takes several ships at once is a SUPERNOVA; killing the ship that killed the own last clone is REVENGE (once; a new death names a new one); a ship shoved into a crash is a KNOCKOUT (see Shoves and knockouts); and there are TORPEDO KILL, INTERCEPTED (a torpedo shot down), OVERTAKEN and IN THE LEAD (a race's place won), CORE CAPTURED and BATTLESHIP DOWN. The crowd erupts for the biggest (multi kill, supernova, triple kill, battleship down, capture), nearly so for a knockout, and cheers for the rest, then settles back to its murmur; the announcer calls the triple and multi kill, the supernova, the revenge and the knockout (unless he spoke a moment ago). One banner stands 2.4 seconds; meanwhile only a moment as big or bigger replaces it (MULTI KILL and SUPERNOVA first, then TRIPLE KILL and BATTLESHIP DOWN, CORE CAPTURED, REVENGE and KNOCKOUT, DOUBLE KILL and IN THE LEAD, TORPEDO KILL, INTERCEPTED, OVERTAKEN). A streak starts over with a new round and with the own clone's death. The moments are only show: they score nothing. Not in the flight school.
- Destroyed ships respawn at the edge of the field, at the best of twelve random places clear of rock: the one farthest from the nearest enemy, preferably out of every enemy's sight behind the asteroids. Where none of them is clear (a dense field, a base among rocks), the first of four dozen more places on the edge clear of rock at all, and as a last resort open space just beyond the field's rocks. A fresh clone has 5 seconds of spawn protection (it blinks); bots leave it alone meanwhile, and firing ends it early (fire held from before the clone was printed does not shoot until it is let go). The Host sits through a sponsor break while the next clone is printed: after 3 seconds an ad appears, and once it has run (6 seconds), a button boots the next clone. A bot's next clone takes as long as a Host's at the soonest: 9 seconds. The round goes on meanwhile.
- Human and alien interceptor are identical apart from their looks. Both hulls are built in code from facets, shaded round where they meet at less than 60° (so the octagonal bodies read as curved) and hard at sharper edges, 344 triangles the human and 256 the alien (the drive flame and glows of the model files come on top): the human interceptor follows the original model (a fuselage with a canopy, two tall fins on struts with the tournament's orange stripe, a gun under the nose, two drives), the alien interceptor is a slim dark dart with a tall dorsal blade, a keel and swept side blades, veined with the turquoise glow of its life support. From the model files they keep only the collider box (so the shared hit radius is the same), the drive flame and the glows at the nozzles.
- **The dodge.** Tapping a thruster key twice within 0.3 seconds (A, D, R or F; two flicks of the thruster stick or the touch push stick work the same way), or LB on the gamepad (the way the thruster stick points, else to the right), fires every maneuvering thruster at overload: a kick of 40 m/s sideways, up or down (weaker with damaged thrusters), a jolt and 15 % g-force strain. The autopilot leaves that drift alone for 1.2 seconds, so the ship plainly leaves the line of fire, about 50 m, more than a ship length; the thrusters need 1.5 seconds before the next dodge. Kicked into a ship alongside, it is a shove (see Shoves and knockouts).
- **Dodging.** The laser hits the instant it fires, so nobody outruns a beam; a dodge beats the aim. Bots sense how hard their target changes its motion across their line of sight (smoothed over 0.6 s) and their aim scatters by it: at half the thrusters' push one ship radius, at most two and a half. Steady flight, however fast, is easy to lead; jinking left and right with the thrusters, autopilot on or off, is what makes them miss. Bots fight for position: each works its way to a point 200 m behind its target, keeps its nose on the target meanwhile and lets the thrusters carry it around; it fires into an open drive and only now and then takes a single shot at armor (in three of ten thinking spells, and only with a laser below 10 % heat), so it keeps the heat for the drive. A ship on a bot's tail that the lock warning would show (within 3 km, in sight, its nose tracking the bot, not in a solar storm) makes it turn its armored nose to that ship, jink left and right and fight back, and so does a hit into its drive from however far, its beam showing where it came from: for 3 seconds the bot defends against the shooter; the flight school's unarmed sparring bot runs instead. Bots steer around the President's battleship as around rock. Their aim also wanders by an angle (about 1.1° for an average bot, less for better ones): one ship radius at 1 km, so a far target is hard to hit. Bots see ships within 3.5 km, across the whole field, and fire only within 1 km. Each bot hunts the nearest ship in sight, but a ship others already hunt counts as farther away, and one hunted by two is left to them; a bot reads who hunts whom from what it sees (ships in sight within 1 km of a ship, their noses within 17° of it), never from another bot's mind. A bot keeps its target unless another is clearly nearer: the bots fight each other too, not only the Host. In a solo round they go easy on a Host who keeps dying: every death by an enemy raises their ease by 0.35 (up to 1), every kill of the Host lowers it by 0.1, and it fades over 90 seconds; at full ease they aim two and a half times worse and pull the trigger 0.4 seconds later.
- A solo round lasts five minutes of real time, like the radio's track, so a slow frame rate does not stretch it. It pauses when the tab is hidden, and while paused. A long frame (a slow device, a time-lapse) is run in steps of at most 1/30 s, and a held trigger fires on the laser's exact cadence, so shots, collisions and bots come out the same at any frame rate.
- The personal best counts solo and tournament rounds; points from the flight school's drones and sparring bots do not count.
- The sponsor break can be paused. If an ad fails or runs too long, the button to boot the clone appears after 20 seconds at the latest. When an ad blocker hides even the satire ads (it hides the ad slot by its name), the break notices that the ad has no size and scolds the Host instead: "You even blocked an ad for products that do not exist. Shame on you. How is an indie developer supposed to make a living?" The clone boots all the same; the check looks only at the page itself and sends nothing anywhere.

## Privacy

The game collects as little as possible: no accounts, no cookies, no tracking, no ad network, nothing loaded from third-party servers. The German legal pages [Impressum](impressum.html) and [Datenschutz](datenschutz.html) are linked from the menu and the radio page. What happens to data:

- **Hosting:** Cloudflare Pages delivers the site and sees connection data (IP address, time, file, user agent); Cloudflare also asks browsers to report failed connections (Network Error Logging). Links to GitHub carry no referrer.
- **Browser storage:** eleven localStorage entries (callsign, personal best, the drill reached in each course of the flight school, the courses completed, how often Nicole's briefings and tips were heard, radio on or off, radio volume, the last solo round's choices, the best lap of each arena's race course with its ghost, the hangar: Solar Coins, the upgrades of the ships and the ship flown, the language chosen); they stay in the browser, only the callsign and the looks of the own ship (type, neon trim, drive flame) are shown to the other players of an online tournament.
- **Online tournament** (only when a Host starts or joins one): the browsers connect directly over WebRTC, so the other players see the Host's IP address, callsign, ship and score. To find each other, the browsers post short connection messages (with network addresses) on public Nostr relays run by independent third parties. Each browser asks Cloudflare's STUN server for its public address; Trystero's default STUN servers of Google are replaced by Cloudflare's alone. Joining fetches short-lived credentials from `/turn`, and where no direct connection is possible the game data runs through Cloudflare's TURN relay (end-to-end encrypted by WebRTC). Every browser checks roughly whether what the others report is possible and tells them when it is not; once a majority of the other Hosts with a place (at least two; watching Hosts have no vote) say so, everyone in the tournament sees the cheater's callsign and stops sending to it. Nothing of it is stored. Opening the list of tournaments connects to the lobby the same way, and the names, codes, modes, Host counts and round times of public tournaments are visible to everyone there; with the code anyone can join.
- **Sponsor break:** invented satire ads, no ad network. The privacy policy has to be extended before real ads are shown.
