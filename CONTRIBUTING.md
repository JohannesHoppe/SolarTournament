So that this right also covers what others add, every contributor agrees once to the Contributor License Agreement below before their first pull request is merged. You keep the copyright in your contributions and may use them for anything else you like.

## How to sign

With your first pull request, add a file `contributors/<your GitHub username>.txt` with this content (your username in place of `<your GitHub username>`):

```
I hereby accept the terms of the Contributor License Agreement in the CONTRIBUTING.md file of the JohannesHoppe/SolarTournament git repository as of October 21, 2026.

Signed: <your GitHub username>
```

A check on every pull request looks for this file, for the author of the pull request, the author of every commit in it and every co-author (`Co-authored-by`). A file the pull request brings counts only when you committed it yourself, in a commit GitHub shows as verified (one made on github.com, or signed with a key of your account): nobody can sign for you. The check labels the pull request `cla: missing` or `cla: signed` and comments on its first run and whenever that changes. A pull request is only merged with `cla: signed`. Commits have to be linked to your GitHub account (the commit e-mail address is one of your account's addresses), co-authors are named with their GitHub noreply address, and a pull request has at most 250 commits, or the check cannot tell who wrote them. You sign only once; your file covers all your later pull requests.
