# docs/campaign

The solo campaign, a story the Host plays alone on the way to the President's Games: it changes nothing in online rounds. It is built chapter by chapter; what is built goes into the repository's `README.md` (story into "The universe", rules with their numbers) and the Pilot's Handbook in the same commit.

| File | What it holds |
|---|---|
| `STORY.md` | The campaign's design bible: premise and arc, acts and chapters, every mission with its goal, failure and pay, the progression, the fourth ship, the worlds, the characters, the black hole, sample dialogue, and how it maps onto the game as built. Full of spoilers. |
